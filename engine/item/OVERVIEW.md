# item/ — 道具子系统

道具 = 敌人/符卡/消弹送出来的那些「点 / P / 樱点 / 时点 / 金钱」实体。
各作的道具**类型号、池结构、掉落驱动**都不同，所以一手证据按版本放 `<版本>/`，
本文件只做跨版本索引 + 断言矩阵。

> **版本**：跨版本。下文出现地址时一律写全 `thXX:0x……`。
