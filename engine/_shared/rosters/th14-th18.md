- **无效道具 type 15**（收下无事、外观被改写成 type 6）—— 只有本作有这种「空道具」。
- **两池道具结构**（`normal_items` + `cancel_items`）与**擦弹道具的缺席**（相对 TH15）—— 见 §5.2。
