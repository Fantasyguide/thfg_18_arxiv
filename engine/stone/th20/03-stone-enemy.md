## §0 一句话结论

异变敌人是一套**「单例控制的遭遇战」**：全局单例 `FUN_00464080(0)` 上的 **`+0x5c`（0..10000）= 槽的当前值**、
**`+0x60`（0..5000）= 该槽的「阈值」**（随主石/难度初值 1100..1400，每次击破 **+150**）；
三条蓄积通道——**擦弹**（`FUN_004a5640` 一段，按 10 档表 `{100,150,…,800}` 加权）、
**Boss 在场上自然上升**（`0x5120d0`：每 3 帧 +2）、**吃异变石道具**（类型 9..12，主槽 +1、该色槽 +10）——
全部写 `+0x5c`，Miss 时 **−100**。`+0x5c >= +0x60` 且场上无存活异变敌人（`ctrl+0xb0 == 0`）时生成：
颜色由**四色分色槽 `+0x64/+0x68/+0x6c/+0x70`（各 0..1000，满 1000 会把颜色闩进 `+0x98`）** 或「分色槽最大者」决定，
身体 = ECL 子程序 `StoneR/StoneB/StoneY/StoneG`（`default.ecl`），攻击 = 子敌机子程序
`StoneAttackLevel_{R,B,Y,G}{1..5}`；**等级 = `+0x74/+0x78/+0x7c/+0x80`（各色 0..4）**，**击破 +1**、**Miss −3**，
等级决定 HP 表 `0x573ff0[色][级]` = `{3200,3400,3700,3900,4000}`。
击破走 `FUN_00511f00`：半径 320 的**道具全吸**（`FUN_0047cf60`）+ 一次广播（`FUN_004caad0`）+ 上面那三件。
**Wiki 口径逐条判定**：擦弹充能 ✅ / Boss 战自然上升 ✅ / 满槽出现且干扰玩家 ✅ / 颜色由异变石决定 ✅ /
Miss 降级 ✅；三处需改：①「击破掉落大量道具」实际是**半径 320 的吸道具**（§5）；
②「连续击破敌人」的中介是**碎片道具**而非直接加值（§2.4）；③「画面左下竖直槽」的绘制者**未找到**（§7 #6 ❓）。
`+0x60` 与 `+0x5c` 谁是槽本文给出了判定（§2.1），**与 [`05`](05-shards-and-items.md) 的 🟡 结论相反**。

## §2 槽的蓄积

### 2.1 判定：**`+0x5c` 才是「异变敌人槽」，`+0x60` 是它的阈值** ✅

[`05`](05-shards-and-items.md) §2.4 把 `+0x5c` 读成「上一条槽的显示/跟随值」并留了 ❓。本文判定相反，四条一手证据：

| # | 证据 | 地址 |
| --- | --- | --- |
| 1 | 三条蓄积通道（擦弹 / 吃异变石道具 / Boss 在场）**与 Miss 惩罚**全部写 `+0x5c`；`+0x60` 只有「初始化」和「击破 +150」两个写点 | `0x4a5640`、`0x4c3215` 段、`0x5120d0`、`0x4f8420`；`0x5333b0`、`0x511f00` |
| 2 | **生成门就是 `+0x60 <= +0x5c`**（`FUN_00513e60(mgr) <= FUN_00499520(mgr)`），生成后 `+0x5c -= +0x60/3` | `0x5120d0`（`FUN_00514260`） |
| 3 | 若 `+0x5c` 只是显示值，则「Boss 在场每 3 帧 +2」「Miss −100」都加在显示值上，槽本身永不上升 ⇒ 与 Wiki「Boss 战中自然上升」直接矛盾 | 反证 |
| 4 | `+0x60` 初值来自一张 8 项表 `{0,1100,1200,1300,1400,1400,1400,1400}`（`0x5333b0`），且**每击破一次 +150** ⇒ 是「越来越难触发」的阈值语义 | `0x5333b0`（`weapon.c:3236`）、`0x511f00` |

`+0x60` 初值的下标来源两处：`*DAT_005c6110`（该符号是结构体基址，Ghidra 呈现可疑 ❓）与
`FUN_0041cab0(mgr)` = `*(mgr+0xc)`。后者的身份可由数据表反推：
`0x5745a0` = `{红,红,蓝,蓝,黄,黄,绿,绿,灰}`（成对！）与 `0x574ec8` = 同色深浅成对，
`stonemenu.c` 用 `FUN_0041cab0(mgr)/2` 索引 4 色 ⇒ **`*(mgr+0xc)` = 当前主石 id 0..7** ✅
（与 [`05`](05-shards-and-items.md) 的「每块石不同」一致）。阈值表逐主石 = `{0,1100,1200,1300,1400,1400,1400,1400}`，
下标 0 为 0 疑为占位 ❓。
