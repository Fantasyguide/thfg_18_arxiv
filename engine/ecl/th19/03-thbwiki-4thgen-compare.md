## 3. ★ 由此得到的行为修正（比 opcode 名更重要）

1. ★★ **早苗 C3 的弹是「曲线激光」**：`609` 设**变换表**、`711` 是**曲线激光发弹**函数 ⇒
   她那条"直上直下 → 到高度转向 90° 横移"就是**曲线激光的路径变换**，不是"普通弹被拉长"。
   ⇒ 卡侧若用"点弹 + 自己算路径"去仿，形状永远对不上；应改用**曲线激光**（或等价的正弦/分段路径）。
2. ★ **魔理沙 C3/C4 的激光是「直线激光」**：`700`（变激光：a/length/b/width）＋ `701`（预警线 a、激光 c、过渡 b/d）
   ＋ `703`（发预警线激光）⇒ **流程 = 先出预警线、再变实**。卡侧现在是"直接画一条竖带"，
   ★ 少了"预警线 → 变实"这两段过渡（`701` 的 b/d）。
3. ★ **`604` 的 `dif` 定案**：表里写明「`dir` 为方向参数，**`dif` 为角度差参数**，作用多样，详见 607 表」；
   `607` 的 style 0 描述「中心方向为(自机方向+dir)，**dif 为各 way 间角度差**」⇒
   ★ 魔理沙 C3 的 `604(−π/2, −π/2)` 在 **way=1** 时 `dif` 无意义 ⇒ 竖直 ✓（与 §4.4 的分布统计一致）。
4. ★ **`606(way, layer)`**：我原来的"两个 u16 计数"就是 **way 数与每 way 层数** ⇒ 卡侧若只做"颗数"，
   少了"层"这一维（不同层速度不同）—— 这正是 `605` 说"各层速度在 [minspd,maxspd] 均匀分布"的前提。
5. ★ **`607` style 0–12** 是完整的**发弹形状枚举**（自机狙/一般/左偏开花/双偏/开花/扁开花/分层随机/速度随机/完全随机）；
   卡侧目前大多是"自己拼角度"，与 style 语义无关 —— 若要贴近一手，应按 style 选发弹形态。

## 5. ★★ `609/610/611/612` 的详解（表里那一节，直接解释了「运动」）

表里原文要点：

* ★ 这四个**本质相同**：都是**给弹幕设置变换**（高级变换），按 `mode` 不同而不同。
* ★ `mode` 是一个 **32 位开关**，**一次只开一个**（所以是 2 的 n 次方）。
  ★ **锦上京（TH19）中，反编译出来的 mode 值用「序号 n」代替 2^n** —— ★ 用表的「序号」列即可。
* ★ **变换序号**从 0 开始**依次执行**；`609/610` 显式写序号，`611/612` 省略但内部仍记（**递增**）。
  ★ **不能跳号**（缺号则后面的都不执行），除非用 `8192`／`32768`／`65536` 这三个可控跳转 mode。
  ★ 循环里写 `611/612` 会**每次都新建变换**（列出非常多），而 `609/610` 反复执行只**覆盖**同序号 ⇒ ★ 这就是早苗 C3 用 609 的真正原因。
* ★ **通道**：`0` = 一个完成后执行下一个；`1` = **同时进行**。
* 其余参数：整数 `a b c d`、浮点 `r s m n`，**按 mode 取用**；不用的写 `-999999`／`-999999.0f`。
  大部分 mode 只要 `a b r s`（⇒ 用 `609/611`）；要 8 个参数的用 `610/612`。

⇒ ★★ **早苗 C3 的"运动"就是这套变换**：

| 段 | 实参（逐字） | 读法 |
| ---: | --- | --- |
| 0 | `609(0, 0, 0, 128, 300, -9999994, -9999994.0f, -9999994.0f)` | seq0／通道0／**mode 128**／a=300 ⇒ 前 300 帧的竖直（直线）段 |
| 1 | `609(0, 1, 1, 8, 40, 0, 0.1, 0)` | seq1／**通道1（并行）**／**mode 8**（切向加速度 r=0.1）／40 帧 |
| 2 | `609(0, 2, 1, 8, $D−40, 40, 0, 0)` | 同上，r=0 ⇒ 直线 |
| 3 | `609(0, 3, 1, 8, 10, $D, -0.4, 0)` | r=**−0.4**、10 帧 ⇒ ★ **转向**（90° 的来源） |
| 4 | `609(0, 4, 1, 8, 8, $D, 0, ∓0.19634955)` | s=**∓11.25°/帧**（自转角速度）⇒ 左右**交错** |
| 5 | `609(0, 5, 1, 8, 120, $D, 0.05+0.05×rank, 0)` | 慢速切向加速度 ⇒ 渐渐偏 |

★★ **结论（owner 2026-10-18 按表现裁定）**：早苗 C3 **就是曲线激光**。
⇒ `609` 的变换序列 = **曲线激光的路径/弯曲参数**（`mode 8` 切向加速度 `r` 就是弯曲率、`s` 是自转/朝向速率），
  `711` = **曲线激光发弹**（表里的说法对）⇒ 视觉上是"**一条连续的曲线在转弯**"，不是"一颗颗弹在飞"。
★ 与 handler 不矛盾：`0x503408`/`0x50388c` 都是"把段表搬进 spawn 描述符再 spawn"——曲线激光正是**沿路径展开的实体**。
★ 贴图：曲线激光的"条"应是**横条**（owner 指认 `laser1.png` 第 5 行，256×16）⇒ 8×8 的 `type 0`（点弹）
  与"激光条"的关系仍 🟡（可能是激光头/节点类型），未证。
★ `711` 是"带路径发射"（把段表搬进 spawn 描述符）—— 与我们的 handler 一手一致；
  表里 `711` 写作"曲线激光发弹"，★ 那是第四世代的说法，**TH19 以 handler 为准**。
