## 0. 一句话结论

TH07 的樱点计数器是**一台 AsciiManager 用「贴图 VM 字形」逐位拼出来的**，不是引擎的 ASCII 文字系统：
`AsciiManager::sub_404690`（`th07:0x404690`，被 `AsciiManager::on_draw_0b` `0x4019e0` 每帧调）画**两行**——

| 行 | 内容 | 位置（相对锚 `T`）| 位数 | 颜色（一手地址）|
| --- | --- | --- | --- | --- |
| 上 | **樱点 Plus（+C）** | `T + (53, 2)` | 5 位定宽 | 平时 `(0xC0,0x80,0xB0)`；**结界中** `R=0xFF` + 呼吸的 `G=B` |
| 下 | **樱点** | `T + (46, 11)` | 6 位定宽 | 满最大樱点 `(0xFF,0xD0,0x80)` / ≥50000 `(0xFF,0xFF,0x80)` / 否则白 |
| 下（接在樱点字段后 **+9**）| **最大樱点** | `T + (97, 11)`（= 46+42+9）| 6 位（值 ≥ 1000000 时 7）| `(0xF0,0xD0,0xE0)` |

* **锚 `T`** = 内嵌 VM2 的 pos，由它自己的脚本（`ascii.anm` script4）滑到 **(32,449)** 定住；
  那台 VM 显示的 `sprite142`（96×16）就是数字左边那块固定标签（🟡 内容未目视确认）。
* **森罗结界指示**（结界中才有的三件，判据都是 `ds:0x4bfee5 == 1`）：
  ① +C 行**变色**（`0x404c27`–`0x404ca2`）；② +C 行**放大 1.41 倍 + 字距 7→10 + 整体 +2/−2**；
  ③ 数字行上**多盖一块脉动板**（VM4 = `sprite143`，脚本 script5，30 帧缩到 1.2 → 30 帧缩到 0.8 → 无限循环）。
* 同期的另外两件「结界中」全局视觉（全屏压暗 37.5 %、自机红白闪）**不是 HUD 元件**，见
  [`01-barrier-visual.md`](01-barrier-visual.md) §4.2/§4.3（本文不重复）。

## 2. 版式：两行 + 定宽右对齐（✅ 逐指令）

### 2.1 数字字形与「怎么出数字」

* **字形** = `ascii.anm` entry0 **sprite132..141**（各 8×12）：VM3 的脚本 `script3` 正文 =
  `ins_3(sprite132); ins_30(1); ins_2();`（`thanm -l 7`）⇒ 一台 VM 显示一个数字位。
* **每一位**：`sprite = 数字 + 0x84`（`th07:0x404a41` `add edx,0x84` 后 `push` → `0x44e8e0` 换图；
  最大樱点那一支在 `0x404d7d`），再 `0x44f770`(draw) 画出来。
* **字距**：每画一位（**含被跳过的前导零位**）`x += 7`（`th07:0x404a71`–`0x404a83`，`fadd ds:0x498c30`）
  ⇒ 字段**定宽**、数字**靠右对齐**；前导零只是**不画**（闸 = `[ebp-0x34]` 的 `started`，`0x404a32`），
  个位 `divisor == 1` 永远画（`0x404a38`）⇒ 值 0 显示 `0`。

### 2.2 樱点行（6 位）| `th07:0x4048de`–`0x404a89`

| 项 | 一手 |
| --- | --- |
| x | `T.x + 40 + 6 = T.x + 46`（`0x404918`–`0x40492d`）|
| y | `T.y + 11`（`0x404936`–`0x404945`）|
| z | `T.z`；alpha 从模板抄（`[VM2+0x1bb]` → `[VM3+0x1bb]`，`0x404963`）|
| 值 | `ds:0x62f88c`（樱点）− `[globals+0x88]`（本关基准）（`0x4048f1`–`0x4048fd`）|
| 位数 | 6（`[ebp-0x38] = 0x186a0` 起，`cmp [ebp-0x18],0x6`）|
| 色 | `樱点 ≥ 最大樱点` → `(0xFF,0xD0,0x80)`（`0x404984`–`0x4049a2`）；否则 `值 ≥ 0xc350` → `(0xFF,0xFF,0x80)`（`0x4049ad`–`0x4049c9`）；否则 `(0xFF,0xFF,0xFF)`（`0x4049cd`–`0x4049e9`）|

### 2.3 最大樱点行（同 y，接在后面）| `th07:0x404a8e`–`0x404ba3`

| 项 | 一手 |
| --- | --- |

| 值 | `ds:0x62f888`（最大樱点）− `[globals+0x88]`（`0x404a95`–`0x404aa7`）|
| 位数 | 6，`值 ≥ 0xf4240`（1000000）⇒ **7**（`0x404ae0`–`0x404b07`）|
| 色 | `(0xF0,0xD0,0xE0)`（`0x404aad`/`0x404ab7`/`0x404ac1`）|

### 2.4 +C 行（5 位）| `th07:0x404ba3`–`0x404dc7`

| 项 | 一手 |
| --- | --- |
| x / y | `T.x + 53`（= 40+6+7，`0x404bc4`–`0x404bdf`）/ `T.y + 2`（`0x404be8`–`0x404bfa`）|
| 值 | `ds:0x62f890`（Plus）− `[globals+0x88]`（`0x404c00`–`0x404c12`）|
| 位数 | 5（`0x404d20` 的 `0x2710` 起，`cmp [ebp-0x18],0x5`）|

| 色（结界中）| `R = 0xFF`（`0x404c27`）；`G = B = v×0xc0/50000 + w×64/2000`（`0x404c50`–`0x404ca2`），其中 `w = v % 4000` 且 `≥2000` 折回（`0x404c2e`–`0x404c4d`）；⚠ 原版**按字节写** ⇒ 和到 256 截断成 0 |
| 尺寸/位置（结界中）| VM3 的 scale `= 0x3fb47ae1`（**1.41**，`0x404cab`/`0x404cb8`）、字距 **10**（`[ebp-0x30] = 0xa`）、整体 `x += 2` / `y −= 2`（`0x404ccc`–`0x404cf3`）|

### 2.5 ★ 锚点：三台 VM 里**只有标签那台**是左上角（2026-09-22 落到 opcode 级，✅）

版式里那些 `+46 / +53 / +97` 全是**相对 `T`** 的，而 `T` 落在素材的哪一角取决于 VM 的锚点 ——
三台 VM 的锚点**不一样**，抄错就是半个字形。一手判据（`AnmVm::Draw` `th07:0x44f770` 用
`vm+0x1c0` 的**位 10/11** 选锚）：

| VM | 载体 | 锚点 | 判据（要点）|
| --- | --- | --- | --- |
| **VM2** = 标签（sprite142 / script4）| `this+0x498` | **左上角** | script4 正文第 3 句 = `ins_22()`（见下）|
| **VM3** = 数字（sprite132..141 / script3）| `this+0x6e4` | **居中（锚心）** | 正文没有 `ins_22`，且装脚本时 flags 被复位（见下）|
| **VM4** = 脉动花（sprite143 / script5）| `this+0x930` | **居中** | 同 VM3 |

* **`ins_22` 是什么**：`AnmManager::run_vm` `th07:0x450d60` 的 opcode 跳表在 `0x4540da`（索引 = opcode + 1）；
  跳表第 22 项 → `0x451b51`：`mov eax,[vm+0x1c0]; or eax,0xc00; mov [vm+0x1c0],eax` ⇒ 置 flags 位 10/11。
* **Draw 怎么用这两位**（`AnmVm::Draw` `th07:0x44f770`）：位 10 置 ⇒ 左边 = `pos.x`（`0x44f849`），
  否则左边 = `pos.x − w/2`（`0x44f80d`）；位 11 置 ⇒ 上边 = `pos.y`（`0x44f8d9`），否则居中（`0x44f89b`）。
* **为什么数字/花是居中**：`AnmLoaded::load_script_into_vm` `0x44ea20` 装脚本时先 `flags &= 0xfffffcff`，
  再调 `AnmVm::reset` `0x4010f0`（它把 `[vm+0x1c0]` 写成 **0x7**）⇒ 位 10/11 = 0，而两支脚本都没置过它们。

### 2.6 ★ 整块计数器的真实包围盒（2026-09-22 算出来，✅ 推导 + 社区旁证）

按 §2.5 的锚点把三个字段 + 标签 + 花都展开（640 字面量单位，`1 单位 = 2 表面 px`）：

| 元素 | x 区间 | y 区间 |
| --- | --- | --- |
| 标签 sprite142（96×16，左上角锚）| `T.x .. T.x+96` | `T.y .. T.y+16` |
| +C（5 位 × 7，居中，字形盒 8×12）| `T.x+49 .. T.x+89` | `T.y−4 .. T.y+8` |
| 樱点（6 位 × 7，居中）| `T.x+42 .. T.x+89` | `T.y+5 .. T.y+17` |
| 最大樱点 6 位 | `T.x+93 .. T.x+136` | 同樱点行 |
| 最大樱点 **7 位**（值 ≥ 1000000）| `T.x+93 .. T.x+143` | 同樱点行 |
| 脉动花 sprite143（48×16，居中）| `T.x .. T.x+48` | `T.y .. T.y+16` |

⇒ **整块 = 143 × 21 单位 = 286 × 42 表面 px**。旁证：§4 那张社区裁图正好是 **143×21** ——
这条**同时**把「数字是居中锚」钉死（按左上角锚展开会得到 147 宽）。

## 3. 森罗结界指示：判据与第三件（✅）

* **判据**：`ds:0x4bfee5 == 1`（**结界中字节**）。读点 6 处：`0x404c15`（+C 配色）/`0x404de1`（脉动板）/
  `0x429cd1`/`0x42f5f7`（**闸住 +C 累加** —— 结界里 +C 是倒计时、不再累加）/`0x432c84`/`0x432cd9`
  （道具在结界中被吸）。⇒ 与 [`../../spirit/th07/01-barrier-visual.md`](../../spirit/th07/01-barrier-visual.md) §4.4 的
  「Plus 每帧被重算成 `剩余/总 × 50000`」是同一件事的两面。
* **脉动板（VM4）** —— 2026-09-22 补：逐像素读出来它其实是**两朵粉色樱花**（sprite 内 `x6..22` 与
  `x26..45`、`y1..15`），不是"矩形板"；`th07:0x404de1`–`0x404e64`：
  `if (ds:0x4bfee5 == 1) { VM4.pos = VM2.pos + (24, 8); VM4.color = [this+0x650] = VM2.color; draw_vm(VM4); }`
  ⇒ **只在结界中画**，位置 = `T + (24, 8)`，颜色跟着模板走；尺度/透明由它自己的 **script5** 演：
  `ins_3(sprite143); ins_30(1); offset24: ins_36(30,4,1.2,1.2); +30: ins_36(30,1,0.8,0.8); +30: ins_4(offset24,0);`
  （v2 号名：36 = `scaleTime`、30 = `zWriteDisable`、4 = `jmp`）⇒ **30 帧胀到 1.2 倍 → 30 帧缩到 0.8 倍 → 跳回开头**，
  永续（`jmp` 的第二个参数把脚本时间拨回 0）。**居中锚**（§2.5）⇒ 实际盒 = `T .. T+48` × `T.y .. T.y+16`，
  与标签的左半重合（它盖在 `Cherry` 那几个字上）。
* 板子画在**数字之上**（它在这段函数的最后，晚于 VM3 的 draw）⇒ 观感是「计数器左半被两朵脉动的花罩着」。

## 3b. ★ 标签 sprite142 画的是什么（2026-09-22 逐像素读出，✅ 一手）

本文原先把这块记成「无法目视确认」。本次用**字符画判读**（把 alpha 与 luminance 按像素打成文本 +
`thanm -l 7` 的矩形 + §2 那些字段偏移三者对位）读出它由**四层**组成，而且**正好对上三个字段**：

| 元素 | sprite 内矩形 | 对上的字段（判据）|
| --- | --- | --- |
| 单词 **`Cherry`**（大写 C + 小写 herry，字高 7 px，`y` 下延到第 13 行）| `x1..36, y5..13` | 樱点字段：首字框 = `T.x+42`（居中锚 ⇒ `±4`）⇒ 标签在它左边，不打架 |
| 粉色加号 **`+`**（5×5）| `x41..45, y1..5` | +C 字段：首字框 = `T.x+49`（5 位定宽、右对齐）⇒ 加号在它左侧 4 px |
| 粉色斜杠 **`/`**（3×8，向左下斜）| `x86..90, y6..13` | 樱点字段末字右沿 `T.x+85`、最大樱点首字左沿 `T.x+93` ⇒ 斜杠落在 8 px 空档正中（空档中心 89、斜杠中心 88.5）|
| 软投影（暗、半透明）| 约 `x1..90, y3..15` | 让数字压在上面时仍读得清（贴图自带）|

★ 这三条对位**只有把数字按「居中锚 + §2 那些死偏移」摆才同时成立** ⇒ 它**反证**了 §2.5 的锚点读法；
交叉印证 = §4 的社区描述「**Cherry** 右侧的分子 = 樱点、分母 = 樱点最大值」。
（`sprite142` 的动画 = script4 的**开机一次**滑入 + 一闪：见 §5。）
