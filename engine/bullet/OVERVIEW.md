# bullet — 弹幕引擎
> **版本**：跨版本。本文出现的地址一律带版本前缀（如 `th16:0x442560`）。


TH16 的敌弹**不是**由一个中央弹幕系统统一驱动的。每颗弹自己带一小段**字节码 VM 上下文**，
运动由 VM 逐帧解释；VM 之外还有一层按位场派发的 **behavior handler**，两者在同一个弹对象里交织。
换句话说：**弹对象既是数据也是执行上下文**。这个设计决定了「改弹幕行为」的接缝在哪——
不在某个 if，而在 opcode 表和 handler 表。

激光是另一个类族（有独立 RTTI 与 vtable），显示、判定、Bomb 取消三件事分开走。

**「消弹」不是一件事，是一族函数。** TH18 的弹幕侧有**五个**入口（`th18:0x428e90` 单弹、`th18:0x429250` 半径、
`th18:0x429370` 半径+转道具、`th18:0x4294b0` 矩形、`th18:0x4297a0` 全屏），**撒不撒实体道具只由一个 `mode` 数决定**：
`0`/`3` 纯删除、`1` 撒小分道具、`4` 撒小分道具 + 少量钱；激光另有一套入口（`th18:0x449010` / `th18:0x449090` / `th18:0x448fa0`）
+ 一处内联写法。所以「清屏」与「击破转道具」在原版是**两条 mode 不同的路**，
「boss 击破满屏弹消失却不出点」不是 bug 而是脚本主动 `etClearAll` 的结果。详见 [`th18/01-cancel-to-item.md`](th18/01-cancel-to-item.md)。

★ **但这个 `mode` 表是 TH18 自己的，跨作一律不可移植** —— 六作「消弹 → 出不出实体道具」的一手核查
（2026-09-15）见下节「消弹口径 × 逐作」；结论是**每一作都必须回它自己的 exe 里读它自己的分派**。

## 消弹口径 × 逐作（TH06–TH17 一手核查，2026-09-15）

> **问题**：「消弹之后，那些弹会不会变成**实体道具**？变成什么？每颗几个？」
> 这个问题的答案**逐作不同，且入参形态都不同** —— 有的作是 `mode` 数，有的作只是一个
> **bool「撒不撒」**，有的作**连这个参数都没有**（写死在函数体内），还有一作**根本没有道具系统**。
> 所以**任何跨作搬运 `mode` 数字的做法都是错的**；下面每行都只在它自己那一作的 exe 上成立。

| 作 | 「撒不撒」的入参形态 | 撒出来的是什么 | 这批里**不撒**的典型路径 | 一手文档 |
| --- | --- | --- | --- | --- |

> ★ **数值单位注记**（2026-09-15 实测，避免把「同一个事实的两种单位」读成矛盾）：
> TH15 的收点带**两个**计数器 —— `th15:0x4e7434` 是 **1/100 单位**的最大得点系计数器
> （`th15:0x43b200` 里先把值 `× 100.0f`（常量 `th15:0x4cffe8`）再 `cvttss2si` 加进去，
> 并钳到上限 `th15:0x4e743c`），另一个是 `th15:0x4e740c`（`th15:0x420f50(n)` 做 `+= n/5`）。
> 而且跳转表 `th15:0x440194` 里 **type 9 与 type 0xa 指向同一条 handler**（`th15:0x43ff4b`）
> ⇒ 消弹撒的 `type 0xa` 与普通点道具**完全同价**：前者 `+200`（= 显示 `+2`）、后者 `+2`。
> **文档里出现 `+200` 与 `+2` 是同一条事实的两种单位，不是冲突。** 其它作的 "+N" 若未实测单位，
> 本表已改为**不写数值**、口径见该作分篇。

### 六条跨作断言（都过了一手）

1. **`mode` 号不可移植，而且多数作连 `mode` 都没有**：TH06 是 `ZunBool`、TH08 是 `arg`、
   TH10/TH12/TH13 是 bool、TH11 **一个参数都没有**（函数体内写死）、TH09 **完全没有道具系统**。
2. **同一个数字在两作间可以语义相反**：TH16 的 `mode 1` **一颗都不撒**，TH17/TH18 的 `mode 1` **撒**。
3. **「全清」通常是「不出货」那一档**：只有 **TH12 是例外**（它的 `etClearAll` 传 `spawn=1`，**照样撒**，
   也是这批里唯一「boss 击破会出货」的作）；TH13–TH18 的 `etClearAll` 弹幕半边一律不出。
4. **激光是不是另一套，三种形态**：TH06 同 manager 的另一个数组；TH10/TH11 **两个 manager**
   （弹 = 数组 / 激光 = 链表 + 虚函数）；TH16+ 两套入口 + mode。**激光侧撒不撒与弹幕侧不一定一致**
   —— TH13 的 ECL 激光侧**一颗都不出**，TH15/TH17/TH18 的激光侧**会出**。
5. **场地门不是同一件事**：TH16/TH17/TH18 是「出界**就不撒**」（外扩 32）；
   TH11 是「把 `item.x` **钳到 ±192**」（照撒）；TH10 是 ±2.0 矩形；TH12 外扩只有 `2.0`；
   TH08 判的是 **y**（`−64` / `448`）；TH09 是 `±144`；TH06 **没有门**。
   ⇒ 讨论「像不像原版」必须说清是**哪一种门**。
6. **RNG**：**只有 TH14 / TH15 / TH16（mode 2/4/5）/ TH17 在撒道具时消耗**随机数；
   TH06 / TH08 / TH10 / TH11 / TH12 / TH13 的消弹链**零 RNG**（确定性；TH06/TH08 的取值调用被
   `state ∈ {2,3,5}` 门关住，消弹一律传 `state=1`）；**TH07 只在 `mode 2`**（走 `state=2` 支）消耗；
   TH09 只有「击杀表现」取方向时消耗。
