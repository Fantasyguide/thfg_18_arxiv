## 1. `.sht` 结构（一手：decomp `src/Player.hpp` + 逐字节核对样本）

```c
struct PlayerShotEntry {        // 一行 = 0x38 字节（TH11 是 0x34、TH18 是 0x5c）
    i16 unk0;                   // 0x0  ← **唯一已知字段**；负数 = 终止符（加载循环 `while (entry->unk0 >= 0)`）
    unknown(0x2, 0x26);         // 0x2..0x25 **decomp 标为未知**
    i32 unk28, unk2c, unk30, unk34;   // 0x28/0x2c/0x30/0x34 = 4 个**回调索引**，加载时被换成指针
};
struct PlayerShotEntrySlot { PlayerShotEntry *entry; u32 unk4; };   // 8 字节一项
struct PlayerRawShtFile {
    u16 unk0; u16 entryCount;   // +0x2 = 组数（一手：ply00as = 6、ply02as = 8）
    f32 bombCount;              // +0x4（一手：3.0 ⇒ `SetBombCount((i32)…)`）
    i32 unk8;                   // +0x8（一手：ply00a = 18 / ply02as = 10；被 `Player` 当"上限"用）
    unknown(0xc, 8);
    f32 itemCollectSpeed; f32 itemCollectRadius; f32 pocY;   // +0x14/+0x18/+0x1c（一手：10.0 / 24.0 / **128.0**）
    unknown(0x20, 0x14); f32 unk34;                            // +0x34（一手：0.9 = **妖怪侧**收集倍率）
    PlayerShotEntrySlot entries[];                             // +0x38 起，8 字节步长
};
```

- **加载器**：`th08:0x44dd70`（decomp `Player::LoadShtFile`）—— 逐组把 `entries[i].entry` 由**文件内偏移**
  重定位成指针（`add ecx, [base]`），再逐行把 4 个回调索引经 4 张表换成指针。终止符 = `unk0 < 0`。
- **两份文件的语义**：`plyNNa.sht` → `player->moveSpeedNormal`、`plyNNas.sht` → **`player->moveSpeedSpirit`**
  （一手 `th08:0x44d650` 一带的两次 `LoadShtFile`）。`g_PlayerShtFile` / `g_PlayerShtFile2` 是运行期那份；
  `pl0Xas` = **妖怪（Spirit）侧** ✓（`ItemManager.cpp:182` 用 `isYoukaiMode ? g_PlayerShtFile2->unk34 : …` ✓）
- **4 张回调表**（一手：`th08:0x44de00`/`0x44de13`/`0x44de26`/`0x44de39` 的 `mov reg,[tbl + idx*4]`）：
  `+0x28`→`0x4c7ee0`(9 槽)、`+0x2c`→`0x4c7f04`(6)、`+0x30`→`0x4c7f1c`(8)、`+0x34`→`0x4c7f24`(8)。
  ⚠ 后两张是**重叠**的（`0x4c7f24` 在 `0x4c7f1c` 的表内部 +8）⇒ 同一个函数可能被两个字段共用。
  表里除了函数指针还有 **难度名字符串**（`Easy/Normal/Hard/Lunatic/Extra`，位于 `0x4b702c..0x4b704c`）
  —— 但**没有任何一行引用到那些槽**（已逐行扫过 8 个文件 227 行）⇒ 那是邻接 `.data` 残留，**行不带难度维度**。

## 4. ★★ 行回调与宿主架构（2026-09-16ze：读 exe 的 6 个行回调，**用户批准只对这 17 个函数读 exe**）

### 4.1 宿主：TH08 的使魔是 **PlayerBulletVm**，不是 shooterset 行

- 自机弹 VM 池 = `[player+0xbe838]` 起 **0x80 槽 × 0x484 字节**；`state` 在 `vm+0x462`（`0` = 空闲）。
- **生成器 = `FUN_00450f60`**（唯一调用者 `Player::UpdateChargeShotTimer 0x451595`）：每帧对每个**空闲**槽，
  按 `g_PlayerShtFile`/`g_PlayerShtFile2`（`+0xe2a74`/`+0xe2a78`）取**组**（组表步长 0x38、行终止符 = `row[0] < 0`），
  逐行调 **`call dword ptr [row+0x28]`（`0x45108b`）**：返回 1 ⇒ 认领该槽并**武装**它
  （`flags |= 0x2000`、`state=1`、`vm+0x480 = row`，并把 `row+0x2c/+0x30/+0x34` 拷进 `vm+0x474/+0x478/+0x47c`）；
  返回 0 ⇒ 同一槽换下一行重试。
- ⇒ **行的四个回调 = 四个不同角色**（不是同一角色的四个阶段）：
  | 行字段 | 装进 | 何时调 | 签名（一手：调用点）|
  | --- | --- | --- | --- |
  | `+0x28` | 生成时**直接 call** | 每帧每空闲槽（生成闸门）| `f(player, vm, frames, row)`（`0x45108b`）|
  | `+0x2c` | `vm+0x474` | 每帧（`Player::UpdateBullets 0x4511c8`）| `f(player, vm)`，**返回非 0 ⇒ 销毁该 VM** |
  | `+0x30` | `vm+0x478` | 画完该 VM 之后（`UpdateBulletVms 0x4513ed`）| `f(player, vm)`，返回值忽略（残影类）|
  | `+0x34` | `vm+0x47c` | 命中时（`FUN_00451670 0x4517e7`，带 `Float3*`）| `f(player, vm, &pos)`，返回非 0 ⇒ 跳过命中 |
- **共用初始化器 `0x44fb70`**（6 个生成闸门都调它）：按 `row` 装填 VM —— 出生点按 `row+0x20`
  （= 0 用自机 `player+0x2b4`，≥1 用 `options[n-1]+0x2a4`）+ `row+0x04/+0x08` 偏移；写判定盒
  `vm+0x430/+0x434`（= `row+0x0c/+0x10`）；写速度（`row+0x14` 角度 × `row+0x18` 模长 → `vm+0x43c/+0x440`）与
  `vm+0x44c = row+0x18`；`vm+0x460 = row+0x1c`（**伤害**）；`vm+0x464 = row+0x22`（**弹种枚举**）；
  `vm+0x46e = row+0x24`（**anm 脚本基号**，弹体 = `+0x24+10`、命中 = `+0x24+11`）；`row+0x26 ≥ 0` ⇒ 播生成音
  （`SoundPlayer::PlaySoundPositionedByIdx`）；`row+0x1e > 0` 且 `GameManager::GaugeIsExtremelyYoukai()` ⇒ 染色。
