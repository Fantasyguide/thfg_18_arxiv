# versus — 对战作弹幕（TH09《花映塚》/ TH19《獣王園》特有：双场地 · 互相送攻击 · 充能轴）

> **版本**：跨版本。本文出现的地址一律带版本前缀（如 `th09:0x4a7d90`、`th19:0x5d1a60`）。

东方正作的**对战型弹幕**只有两作：**TH09《東方花映塚》**（2005）与 **TH19《東方獣王園》**（2023）。
TH19 的官方口径是「**画面构成大体基于 TH09，但重构了系统**」，所以这两作共用一套骨架直觉，
细节却换过一轮。放在 `engine/versus/` 而不是 `th09/`、`th19/` 目录下，是照本仓规矩：
**特有机制也是子系统**，版本只做列。

```
两侧对称场地（side 0 / side 1）
   │ 每侧各自一套：stage / 自机 / 弹幕池 / 敌机池 / 特效 / GUI
   ▼
各侧打自己的敌人 → 攒「充能轴」（TH09 = 容量+当前量；TH19 = 蓄力 5 段）
   │ 攒满/发射
   ▼
★ 把攻击「送进对手场地」 ──► 落到对手的 敌机池 / 弹幕池（不是自己场上多一波敌人）
   │
   └─ 对手侧被压制 → 血量归零 → 判胜（TH09 一局；TH19 另有比赛规则菜单）
```

一句话：**对战作 = 「两块场地 + 一个送东西的通道 + 一条充能轴」**。
单人作里没有「对手场地」这个概念，所以复刻到本仓（TH18 宿主）时必须先决定**「送」的落点**改成什么。

## 版本脉络（两作差异，逐条都有一手）

| 事 | TH09 花映塚 | TH19 獣王園 |
| --- | --- | --- |
| 充能轴 | **两个数**：容量 `+0x30388`(0..400) + 当前量 `+0x30384`；发射 3 档扣 100/200/300 | **蓄力 5 段**：`AuraCtrlInf+0x94` 按 rate 涨，rate 由 `S+0x88` 决定；满段打断对手 |
| 送出去的载体 | effect 载体走贝塞尔 60..160 帧，落地函数写在载体 `+0xbc` | 换全局「生成侧」`0x5d19bc+0x710` = `1-owner`，并把新对象挂到**对手** EnemyCtrl |
| 资源/特殊单位 | 霊 4 型（容量+400 / 灌对手弹幕 / 分数 ×2）| 動物霊 3 族（狼/獺/鷲）+ 除霊オーラ + バリア |
| 灵力/清弹 | 符卡 + 充能攻击 | **霊撃 == Bomb**（同一资源字段 `S+0x68`！）|
| 卡牌/能力层 | 无 | **沿用 TH18/TH18.5 的卡牌系统**：`AbilityCardInf` 23 槽 ≈ TH18 的 21 槽 + 2 个新钩子 |
| 模式 | Story / Extra / Match（参数级差异）| Story（19 角色解锁）/ VS / 规则菜单（`GameRuleTaskInf`）|

## 对本仓（TH18 宿主）的含义

1. **「送进对手场地」在单人宿主里没有对手** ⇒ 复刻时必须先定落点（送成一波敌机 / 送成一波弹幕 / 送成一个道具环）。
   一手的两条落点实现正好给了两个可借的模板：th19 的「换生成侧 + 挂到某个 EnemyCtrl」与 th09 的「载体落地回调写对手池」。
2. **TH19 的能力卡与 TH18 同源**（23 槽 vs 21 槽、对象 0x60/0x64、flags 位置只挪了一格）
   ⇒ 119 卡若走「能力卡」路线，本仓 `mods/th18.v1.00a/card-expand/` 的骨架几乎可直接套。
3. **别重复造**：TH19 的「霊撃」与「Bomb」是**同一个字段**，而本仓 117 卡已经有「霊撃」；
   119 若也用霊撃，要明确它与 117 的资源/优先级关系。
