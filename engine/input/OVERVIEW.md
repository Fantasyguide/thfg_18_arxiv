# input/ — 输入装配线

> **版本**：跨版本。本文出现的地址一律带版本前缀（如 `th18:0x4ca428`）。

游戏输入不是「键盘状态」，而是每帧重算的几个 16 位掩码：**硬件输入 → 游戏输入位 → （各作自己的）
派生/组合位 → 边沿工具**。位布局在 TH10 与 TH11 上**完全一致**（方向 `0x10/0x20/0x40/0x80`、
`0x4` 低速、`0x1` 射击、`0x2` 灵击），但**派生位各作不同**：TH10 把「射击按住 8 帧」派生成低速位 `0x4`，
TH11 把「射击 + ↑ 同帧」派生成组合位 `0x400` 并用它切子机形态。TH18 则是 `INPUT` + `INPUT_PRESSED` 数组。

**边沿检测的形状也换了代**：TH10/TH11 没有「本帧新按下」数组，判定一律是「现帧 `test` 一次 + 上帧快照 `test` 一次」
（TH11 另有一个通用工具 `th11:0x40de10` 产出「新按下/新松开」两个掩码）。

## 开放

- ❓ TH10 的「派生输入字」低位映射与方向解码用的那一套**对不上**（`th10:0x429814` 测 `al,0x1`，
  而方向解码把「上」放在 `0x10`）⇒ 那一处派生位的**按钮身份**未定（不影响「TH10 没有双击」的否定结论）。
- ❓ `th11:0x4c92b0` / `th11:0x4c92b4`（菜单重复键判定用的现帧/上帧对）的写入者未找到 —— 字节子串穷举在这里不可靠（立即数假命中）。
- TH18 侧的「双击窗口」与「组合位」如何承载，本文未考察（TH18 的输入面见 `th18/` 与 `card/`）。
