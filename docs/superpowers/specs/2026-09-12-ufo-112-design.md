### 3.4 吸收 = `on_item_frame` 里的伪磁场（`REVIEW` §8 一手闭环）

- **断点** `0x446ee3`（`on_item_frame`）：每个正常游玩帧、道具池 body `0x445a80` **之前**到一次
  ⇒ 本帧直写的 `pos` 之后仍会被 state 1 物理叠一点（`REVIEW:1002`）⇒ **写 `pos` 的同时必须清 `vel`**。
- **扫池**：`CE_ITEM_MANAGER()` `0x4cf2ec`（⚠ 不是 `0x4cf2bc`，那是弹幕管理器）、
  `CE_ITEM_POOL_OFF` / `CE_ITEM_SLOTS`（4696）/ `CE_ITEM_STRIDE`（`0xc94`）—— **用宏，别写裸数**（`engine.h:403-407`）。
- **吸谁** ✅：一手 `th12:0x4271c0` 只吸**类型 1 与 2**（`UFO:204-207`：类型 1 = P 道具、类型 2 = 点道具）。
  TH18 侧同一个 `type` 字段：`1` = 火力道具、`2` = **金钱**（`SHOP:301`）⇒ 与用户定案 ⑦「蓝点 == 金钱」自洽。
- **怎么吸** 🟡（距离 / 速度的一手值见 §4）：`pos`（`CE_ITEM_POS`）+ `vel`（`+0xc38/+0xc3c/+0xc40`）。
- **怎么消** ✅：直接置空槽，**不走** `0x44658a`（collect 尾）：
  `state = 0` + `ce_anm_delete(*(uint32_t *)(slot + 0xc28))` 并把该字段写 0（`REVIEW` §8.4）。
  ⇒ `on_item_commit` / `on_item_collect` **都不触发** ⇒ 与 114 批集**零冲突**，且**吸收不计分**（正是要的）。
  ⚠ 代价：不走空闲链表 ⇒ **该槽本局不复用**（4696 槽够用；要严谨就补 `ce_item_despawn()`，§3.6）。
- **围栏** ✅（`REVIEW:1012`）：① 目标点必须留在屏内（`|x| ≥ 200.0` = `0x4b9340` 或 `y > 472.0` = `0x4b93a4`
  ⇒ 引擎**当帧就删**，`0x445e38`）；② 目标点离自机必须 > **30 px**（`0x44620a` 的收点检查会把道具收掉）；
  ③ 跳过 state 3 / 4（引擎的真空飞行 / 70 px 环吸，别抢）。

## 7. AUDIT 要点

- **扫池成本**：4696 槽 × stride `0xc94`（池共约 15 MB，`engine.h:406-407`）**每帧一遍**；
  110 也打算在 `on_item_frame` 扫同一池（`audit` §5「跨卡·成本」）⇒ 两张卡各扫一遍 = 每帧 2×4696 次跨页访存，
  **叠加成本没人评估过** ⇒ 本卡要实现「早停 / 只处理 type 1、2」并记录实测帧耗。
- **围栏三件**（§3.4）与 **`vel` 清零**：少一样就会「道具被引擎当帧删掉」或「被自机 30 px 收点吃掉」。
- **槽泄漏**：`state = 0` 不走空闲链表 ⇒ 跑完一关统计槽占用；不接受泄漏就必须上 `ce_item_despawn()`。
- **死亡断点**：`kind` 过滤**必须排除 `KILL_ALL`**（`0x4307f1` / `0x430a00` / `0x430c08`），
  否则计数器被过场刷满（`DEATH:262`）；回调里**禁止析构别的敌人**、**禁止缓存 `enemy` 指针**（`DEATH` §2.4）。
- **`flags_lo` 位语义**：TH18 `flags_lo & 0x21` 置位 = **伤害免疫**（`DEATH:163` 一手订正）
  ⇒ **严禁**把 TH12 的 `flagSet(15)` / `flagSet(1090)` 位号照搬（§1 末行）。
- **删卡路径（METHOD 铁律）**：UFO / 令牌还在场上时被倒吊人或原版空白卡删掉 —— 商店里 AbilityManager 被冻住，
  只有 `on_delete`（`+0x50`）跑得到 ⇒ `ufo_finish()` 必须在 `on_delete` 里也调（不能只挂 tick）。
  ⏳ TODO：**卡被删时留在场上的 UFO 敌机怎么收**（SDK 没有「按 id 析构敌人」的 helper；且死亡栈里不许析构）。
- **replay 安全**：全程确定性；任何随机必须走 `ce_rand()`（回放安全 RNG，`sdk.h:346`），**禁止 CRT `rand()`**（`SDKMD:217`）。
- **与 114 / 110 / 111 的交互**：置空槽不走 collect / commit ⇒ 114 批集、110/111 的 PV 注入都**看不到**（`REVIEW:1027-1028`）；
  ⚠ 但吸掉 `type 2` = **少拿 MONEY**（`SHOP:20`）⇒ 经济影响 ⏳ 待拍。
- **自写 ECL**：名字查不到时 `EclRunContext::ecl_run` `0x48b3a0` 会干净退出（`REVIEW` §6.1）⇒ 占位期可先用惰性壳验证管线。
