## 0. 一句话

**被动卡「花映塚」**：按住 **Z** 蓄力（**本帧不发原生弹** —— 用户：「得拦 Z，这是花映塚的魅力」），
松开按等级发 **CA**（红圈消掉圈内**所有**弹幕、给无敌）；
**击破**产生**蓝色爆风**（只消圈内**白弹** = 半径 ≤ 4.0，转成分，按连爆质量回气）；
**Shift = 固灵**（吸灵领域把幽灵变**活化灵**：HP 减半、缓慢上浮、超时自爆）；
**消弹与击破填 SP**，到 **10 万 / 30 万 / 50 万** 触发一次 boss attack（占位）。

## 4. 引擎面

### 4.1 白弹阈值 T = 4.0（一手，直接用）

- 半径字段 = `zBullet + 0x658`；出生时从弹种表 `0x4c5f90`（stride `0x118`）的 `[+0]`（= `0x4c6094`）拷入。
- 判据：`0 < r ≤ 4.0` = **白弹**；`r > 4.0` = **不可消**（蓝圈消不掉）；`r == 0` = 哨兵弹种（7 个，不参与判定）。
- 落代码：`POFV_WHITE_R_MAX 4.0f` + `pofv_classify_bullet_radius()`（`pofv_core.h`），
  单测覆盖 `{2.0, 2.4, 2.8, 3.2, 4.0}` 白 / `{5.0, 6.0, 8.0}` 不可消 / `0.0` 哨兵。

### 4.2 拦 Z（`0x45ebfb`）—— 用现成事件，不碰输入位

- SDK 侧**已实装**（`sites.py:799` 的 `ce_shot_set_index` 断点 + `sdk.c:764` 的 suppress 分支）：
  handler **先问** `on_shot_set_index`（117 咆哮覆写 set ⇒ 本帧**不抑制**），没人覆写时再逐个问
  `on_native_shot_suppress`；任一卡返回非 0 ⇒ `return 0` + `regs->retaddr = 0x45eca0`
  ⇒ **跳过原生行循环、保留 `0x45eca0` 起的卡广播**（77 / 116 不受影响）。
- 本卡的 suppress 条件（`pofv_charge_suppress`）：**按住 Z 且已升到 ≥ C1 且气槽 ≥ 1**。
  还没升到 C1 的那几帧返回 0 ⇒ 点射照发（§3）。
- ❌ 不做：写 `0x4ca428`；碰 `player+0x4779c`；碰总门 `player+0x476ac`。

### 4.3 击破信号 = `on_enemy_death`（共享广播，只读）

- 断点 `0x430240`（`Enemy__die` 入口，`cavesize 6` / `558bec83ec14`），**在引擎撒主掉落之前**、链表仍挂着；
  SDK 侧**已实装**（`sites.py:793` + `sdk.c:1156`），沿卡链表广播 `ce_enemy_death_t`。
- 本卡过滤：**`kind == CE_EDEATH_KILLED`**（一手：`retaddr 0x42f3b7`，life ≤ 0 的主路）**且** `flags & CE_EDEATH_F_REAL`。
- ⚠ 契约：回调里**不许析构敌人**、**不许缓存 `ev->enemy`**、不改掉落表（110 才需要改）。
- ★ **性能（review §4.1 强制）**：清场帧一次被调 100–300 次 ⇒ 回调里**只入队 + 掉灵魂**（全 O(1)），
  真正的消弹在 `on_tick_2` 帧末按预算做（§6.3）。

### 4.4 消弹的两个调用点（★ 本卡的核心引擎面）

**全 EXE 的消弹入口只有四个**（review §6.4）：`0x4297a0` 全屏 / `0x429370` 半径 + 转道具 /
`0x429250` 半径不转道具 / `0x428e90` 单弹；**没有任何带 exclude 数组的版本**。

| 圈 | 调用点 | 条数怎么来 | mode |
| --- | --- | --- | --- |
| **蓝圈（爆风）** | **自扫弹池 + 逐弹调 `Bullet__cancel 0x428e90`** | 自己数（判据 = 半径 ≤ 4.0）| **1**（加分 + 掉点道具 = 转成分）|
| **红圈（CA）** | `ce_cancel_radius(pos, r, max, mode)`（`0x429370`）| ★ **用它的返回值**（调前清 `CE_BM_CANCEL_COUNTER 0x7a41e8`、调后读）| **0**（纯删除）|

- 蓝圈为什么必须自扫：引擎的半径消弹**没有 exclude**，而蓝圈**只准消白弹**（不可消弹在蓝圈里必须活下来）。
  自扫判据照 `0x429370`：`state ∈ {1,2}`（`+0xf68`）+ `dist² ≤ (弹半径 × 0.5 + R)²`，其中「弹半径」处用 T = 4.0 筛。
- 红圈为什么走现成件：原版红圈**消圈内一切**（含不可消）⇒ 不需要 exclude ⇒ 直接用引擎件最省，
  且**顺手拿到颗数**（review 那条「要自扫池 + 逐弹调 `0x428e90`」只对**需要筛**的场合成立 —— 这是本次的订正）。
- ⚠ **激光是另一套**（`ce_cancel_all_bullets` 里那个 `CE_FN_LASER_CANCEL_ALL`）：本卡**先不做**，
  标 TODO（原版红圈对激光的行为未核）。
- 裸地址（`engine.h` / `sdk.h` **没有**包装的，只在这里出现）：`0x428e90`（`Bullet__cancel`，
  thiscall(弹指针; mode)）、`+0x658`（弹半径）、`+0x24`（不可消位 —— 本卡**不写**，只记差异：
  `0x428e90` 不认它，`0x429250` / `0x429370` 认）。

### 4.5 无敌：走声明层，不直写计时器

- 用 SDK 的 `ce_invuln_request(id, frames)` + `ce_invuln_apply()`（`EVENTS-CONTRACT.md` §4 的**声明层**：
  层取最大值、只在更长时写 `player+0x47774`）⇒ **不会截短** 107 结界 / 117 霊撃 给的长无敌。
- 本卡每帧开头 `request(id, 0)` 退掉上一帧的声明（退掉不会缩短已拿到的计时器）。

## 6. 状态机（判定细则）

### 6.1 蓄力与气槽

```
Z 上升沿            → phase = HOLD, hold_frames = 0, level = 0, max_level = min(gauge, 4)
按住 Z 每帧         → hold_frames++, level = min(hold_frames / FRAMES_PER_LEVEL, max_level)
                       升级那一帧 → 卡侧播「叮」（一手：每升一级一声）
拦 Z（suppress）    → phase == HOLD && level >= 1 && gauge >= 1
Z 落下沿            → level >= 1 且 gauge >= level ⇒ 扣 gauge -= (level − 1)、发动 CA level
                      否则（点射 / 气不够）⇒ 什么都不做（原生那一发照走）
打断（对话等）      → phase = IDLE，**不扣气、不发动**
```

### 6.2 CA / QCA

### 6.3 爆风连锁与队列（性能是硬约束）

- 击破 → `pofv_chain_register_kill(frame)` 给出连爆档（窗口内 +1、窗口外回 1、封顶 4）→ **入队**（O(1)）。
- `on_tick_2` 帧末按 `POFV_BLASTS_PER_FRAME` 的预算出队执行：自扫白弹消弹（mode 1）→ 记账（回气 + SP）
  → 一个矩形伤害源（「有攻击力」）→ 圈内灵魂吃伤害；**灵魂被击破也产生爆风**（连锁，再次入队）。
- 队满 = 丢（计数 `dropped` + 一行日志），**不崩、不影响别的系统**。

### 6.4 SP 三档

- 蓝圈消弹、击破都填 SP（红圈消弹也填）；SP 跨档 ⇒ `pofv_sp_take_attack` 返回 1（**跨两档只报一次**）⇒
  触发一次 boss attack（占位 = 无代价 C4 红圈、**不给无敌**，见 §8 第 2 条）。

### 6.5 固灵与活化灵

```
击破 → 掉一颗灵魂（池 32；普通幽灵 HP = 2，**只有爆风打得动**）
Shift 按住 → 领域（圆心 = 自机、半径 96）内的未活化灵魂 → 活化灵：HP 减半(→1) + 自爆倒计时 180 + 上浮
活化灵每帧 → 上浮 0.5 px + 倒计时 −1；到点 ⇒ 自爆（3 颗占位伤害源）
爆风波及 → 圈内灵魂吃 2 点伤害（普通/活化都一击破）⇒ 击破的也产生爆风（连锁）
```
