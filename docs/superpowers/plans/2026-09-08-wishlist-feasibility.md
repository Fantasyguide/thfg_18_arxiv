## 1. 承载面盘点（现在有什么，能承载什么）

SDK 事件（`native/sdk.h` 既有）：`on_load` / `on_tick` / `on_tick_2` / `on_tick_shooters`
（射击每帧）/ `on_draw` / `on_hud_anm`（HUD 每帧）/ `on_activate`+`on_active_tick`（主动卡 C 键
模型，神之宣告/青眼先例）/ `on_shop_open` / `on_stage_start` / `on_run_reset` /
`on_bullet_created`（自机弹出厂，改伤改参）/ `on_death_before_deathbomb` +
`on_death_after_deathbomb` + `on_death_frame2`（**中弹/决死系三钩子，语义待 RE = G2**）/
`on_enemy_drop` + `on_enemy_drop_pre`（**敌击破掉落前后，加倍 id 69 已用**）/
`on_item_frame` / `on_item_collect` / `on_item_commit`（道具三件套，辉针城用）/
`on_power_level_change` / `on_shot_damage`。

帮手：`ce_spawn_item`（`0x446f40` ABI 已封装，type 1..0x13 池）、`ce_cancel_all_bullets`
（全屏消弹 → 弹/激光转点道具，神之宣告 O28h 用过）、`ce_cancel_radius`（半径消弹，青眼挡弹）、
`ce_damage_rect`（矩形伤害源，光束）、`ce_raise_damage_cap`、`ce_add_score_delta`、
数字/倍率弹字、`ce_gui_update_lives/bombs`、扣火力（炎魔 id 72 先例）、场 VM +
`ability.anm` 演出（龙、横幅）、自绘 HUD（真银圣剑剩余次数、青眼血条 = drawRect 双根 VM）。

**缺口**（要新 RE/新基建的）：① 场上自由实体（飞碟/动物灵/灵 = 减速飘动 + 停留变色 + 判近吸附，
道具池 type 固定装不下 → G5）；② 逐弹染色/状态机（th15 擦弹变色 → G7b）；③ graze 逐帧事件、
消弹挂点、回收线全收原语（→ G1/G3/G4）。其余几乎所有系统 = 上述面的组合。

## 3. 逐作条目（按用户「要点」收敛，非全系统搬运）

### th07 妖妖梦 —— 樱点 + 森罗结界｜预研级 B+（拆 2 卡）

- 樱点槽（Plus 0→50000）+ 结界状态：全逻辑（计数/HUD 用 `on_hud_anm`），获取途径 =
  graze 事件（G1）+ 击破/消弹（G3）+ 道具。
- 结界 7s：自动收（G4）+ 擦弹加值 + 结束 bonus（G6 可作时间自然结束的对齐点）；「中弹 →
  灵击并转弹为樱点」吃 G2（若能消费中弹）→ 结界从「被动槽」升格为「保命卡」。
- 原生弹幕全消 → 小樱点 = G3 产物表复用。

### th08 永夜抄 —— 刻符/人妖｜预研级 B（简化版）；原义级 C/不做

- 要点即「只做使魔联动」——**TH18 无使魔实体**，使魔攻击/伤害转移无从承载 → 原义不做。
- 简化可取：低速=妖怪、高速=人类（focus 位现成）——逢魔侧行为事件化：
  人类高速命中击破出刻符、妖怪低速擦弹出刻符（G1），收刻符 = 得分/资源。
- 决死语义卡（若 G2 支持）= 「可设次数的自定义决死」小卡，另立。

### th10 风神录 —— 灵击 + 信仰 + 满 P 转化｜预研级 A/B（拆 3 卡）

- **灵击卡（A-）**：火力当 bomb 用。扣火力 helper 有炎魔先例；无 B 判定（bomb 计数可读）；
  灵击 = `cancel_all`（G3 产物）+ 伤害面（`damage_rect` 先例）。最有把握的一张。
- **信仰卡（B）**：计数 + 连击条（满槽 = 130 f 经验表已抄进 txt）+ miss 减 / 空槽衰减
  （每帧逻辑）+ HUD。蓝点「吃黄」改分走 `on_item_commit` 拦截（辉针城同款路径）；收点线下
  方吃黄线两段式 = 简化或不做。
- **满 P 转化（B-）**：先验 G8（TH18 原生是否已把满 P 的 P 道具转化）；要点「信仰点与 P
  同时生成」= `on_enemy_drop_pre` 加 spawn（掉落钩子现成）。

### th11 地灵殿 —— 信号系统｜预研级 B

- 信号槽（0–130）：回收线上 +50/f、线下 −0.3/f、擦弹 +8/f（G1）、被弹归零（G2 顺带）。满
  100+ 自动收 = G4。
- 蓝点得分 = f(信仰, 信号) 的原义公式 = 简化（分值改道经 commit 拦截）；保留「信号满自动
  收点」这一个手感面即达用户要点「信号系统」。

### th12 星莲船 —— UFO｜预研级 C（原义）；B+ 简化待 G5

- 用户要点「部分敌人替换为掉飞碟的敌人」：掉落替换 = `on_enemy_drop_pre` 完全能承载
  （按概率/按敌人把原掉落换 UFO 计数）。
- UFO 本体（飘行收集道具、变色序列、击破开箱/自爆、金/虹稀有）卡在 **G5 实体模板**。
  G5 若双轨可行 → 简化 UFO（无金/虹、固定路线）可到 B+。

### th13 神灵庙 —— 灵 / 灵界｜预研级 B（简化版很顺）

- **灵界卡（B）**：灵界槽（600）= 逻辑计数；满 → C 键或 miss 时进灵界（miss 分支吃 G2）=
  数秒无中弹判定 + 擦弹判定保留（原生无敌窗语义，黑桃 A 已玩过复活计时器）+ 角色化小效果。
- **灵收集（A/B 简化）**：击破/Boss 伤害产出蓝灵（分数）、连击产白灵、红/绿 → 残/雷碎
  spawn（现成 ABI）——本作简化版最接近「辉针城卡的镜像」，依赖最少。
- 原义级（近身自动吸、H/L 双倍、灵界 +100 最大得点）等 G5/G8。

### th15 绀珠传 —— 章节 + 擦弹变色｜预研级：章节奖 B+，变色系统 C

- **章节奖卡（B+）**：每 boss 阶段边界（G6）结算「章节内 graze × 击破率 × 5000」；击破率 =
  阶段内敌击破计数（死亡掉落钩子可兼作击破事件）；≥100 万 → 残/雷碎（完美模式→雷碎 =
  简化只给残碎亦可）。一张卡闭环，且分数/资源双输出。
- **擦弹变色系统（C）**：逐弹染色 + 维持后复原 + 掉擦弹道具——子弹系统逐弹状态机是
  新引擎面（G7b），且与「擦弹数缓增」语义纠缠 → 放最后，或永不做（要点原文
  「能做则做」）。

### th16 天空璋 —— 季节子机/解放｜预研级 B（简化版顺）

- 承载面全现成：主动卡模型（C 键已被占用 → **G7 键 remap 成 D/S = 用户点名要的**）、
  子机 VM（破损核心电球先例）、解放 = `cancel_all`（G3 绿点产物）+ 原生无敌窗 +
  伤害面（`damage_rect`/`raise_damage_cap` 先例）、季点 = 击破/擦弹（G1）+ 等级经验表
  （txt 已抄：100/230/390/590/840/1140）。
- 简化方案 = 四季节效果卡选一 + 等级 1–3 封顶（原义 1–6 级 + 土用 + EX 全做 = B+ 大）。
- 绿点「+最大得点」吃 G8；每张解放卡是 A/B。

### th17 鬼形兽 —— 动物灵 / 咆哮｜预研级 A/B（用户「至少」线）

- **资源灵直出（A）**：掉落替换/追加 → 残碎/雷碎/点道具（蓝眼/加倍同款掉路面），
  不做灵实体（原义 C 等 G5）。
- **咆哮卡（B）**：攒 5 灵 → 咆哮（自机下方进度条 = HUD 先例）：**抵消一次中弹** =
  G2 成败定 A 或 B；抵消不可行的垫底 = 咆哮期 `ce_cancel_radius` 贴自机持续消弹
  （青眼挡弹同款思路，半径≈判定）——保命面仍在，只是从「撞弹不死」变「弹近即消」。
- 暴走红/绿/紫强化（低/高速火力 +N%、水獭消弹环）= `on_bullet_created` 改参 +
  `cancel_radius` 环，原样可行。
