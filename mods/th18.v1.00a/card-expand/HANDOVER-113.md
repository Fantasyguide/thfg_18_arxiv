## 4. 纪律与流程（新会话必读）

- **构建/部署**：`cd mods/th18.v1.00a/card-expand/native && make check`（必须 rc=0）→ `MODKIT_DIR="/mnt/d/项目/幻想指南/18/th18_modkit" NO_GIT=1 make release` → `cd /home/nipporita/renkolab && bash local/sync_modkit_dll.sh`（**四路径同 md5 才算部署完成**；游戏在跑时 `thcrap/bin/...` 会被锁，别杀进程、让用户退游戏）。
- **断点**：新增 `BP_*` 必须同步 `native/sites.py` / `native/th18_card_expand.def` / `dllverify` 计数，且站点窗口 **≥5 字节**、不含相对寻址（历史上 3 字节站点被 thcrap 拒收 ⇒ SDK 门 FAIL ⇒ 新卡 id 被禁 ⇒ 玩家看到卡图变垃圾 + 编成槽消失）。
- **不要改 ECL**（除非用户点名）；文档改动后 `python3 tooling/check-docs.py` 必须过（跨版本文档里地址**必须带 `th13:`/`th18:` 前缀**）。
- **创造性选择（音效、颜色、手感）以用户耳朵/眼睛为准**，一手数值只作参考；所有 ❓自定 都要进 `TUNING.md`。
- 术语：**原生** = 引擎（TH18）自带；**原版** = 被复刻的游戏（TH13 等）。
