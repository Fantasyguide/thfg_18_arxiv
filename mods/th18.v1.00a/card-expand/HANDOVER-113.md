## 2. ★ 大件待办：灵界版 BGM

**用户需求**：灵界期间 BGM 变成"灵界版"（TH13 那套）。用户明确：**灵界版音频暂时没有**，之后会拿**一段简单处理过的 BGM** 来测。

### 2.1 TH13 一手结论（已核，别再猜）

- TH13 **不是双轨**：**单条 buffer**（`th13:0x47587f` 写 `1`）。
- 灵界进/出 = **换曲名 + 硬切**：`TranceManager::begin` `th13:0x405a20` 把当前曲名 `th13_04.wav` 的扩展名点覆盖成 `'b'`（`th13:0x405b1d` 写 `0x62`）⇒ cmd9 里 **Stop 旧流 → 重装 → Play**（`th13:0x476ea0`）。
- **但会 seek 到同一播放时刻**：`th13:0x476ed9` 读 `fmt+0x24`(nAvgBytesPerSec) × 当前播放时间（`FUN_00476e00`）− block align ⇒ 新轨字节偏移。
- **b 轨是预录的另一版**（不是运行时合成）：`thbgm.fmt` 里 13 对 `th13_NN`/`th13_NNb` 的 **intro/loop 秒数完全相同**，b 是 22050 Hz、正常 44100 Hz（字节数正好 2×）。
- **没有运行期 DSP/变调/pan/交叉淡化**：BGM 区只用到 DirectSound 的 Lock/Play/SetCurrentPosition/SetVolume/Stop/Unlock；全 exe 无 DSFX/EAX/reverb；灵界路径**不经过**那套单流 fade 状态机（`th13:0x43d0c0`，它只服务菜单）。
- ⇒ 用户听到的"换了别作 BGM 开灵界仍会变"= **只换了正常轨、灵界时引擎按名字找的是原 `th13_NNb.wav`**；判别实验必须**两段都换 + 同时改 b 的 fmt**（b 的 22050 是坑）。

### 2.2 TH18 侧能力（一手）

- 也是**单条 buffer**（`th18:0x489c3a` 写 `1`）；BGM 全局 `th18:0x570484`。
- 可用的运行期原语：`th18:0x48a5a0`(SetVolume，`-10000`=静音)、`th18:0x48a440`(Play)、`th18:0x48a620`(Stop)、`th18:0x48af10`(切轨/seek)、`th18:0x48a1a0`(buffer 填充)；**内存流构造器 `th18:0x4898f0`**（cmd2 preload 走它）。
- **同源的单流 fade 状态机还活着**（`th18:0x453460`，菜单在用，常量与 TH13 `th13:0x43d0c0` 逐条相同）。
- **TH13 的"改名 + 硬切"在 TH18 是死入口**：switch 表 `th18:0x4776cc[8] → th18:0x477276` 代码完整，但全 exe **35 个入队点没有任何 cmd=9**；且 TH18 数据里**没有 `NNb` 轨**（`thbgm.fmt` 只有 `th18_01..18` + `th128_08`），`th18:0x56d104`（当前曲名）也没有任何 b 改写点。

### 2.3 三条实现路线（**待用户拍板**）

| 路线 | 做法 | 代价 / 风险 |
| --- | --- | --- |
| **A（推荐）** | DLL 侧用 `th18:0x4898f0` 从**内存 PCM** 建**第二路流**，`th18:0x48a440` 起播；每帧用 `th18:0x48a5a0` 同时 ramp 第二路与主 BGM（先把主 BGM 的 fade 状态清 0）；退出反向 ramp + 释放 | **不用改数据**（适配"用户自备一段处理过的 BGM"）；风险：与暂停/设备丢失/死亡栈的交互；可额外做 **≈200ms 交叉淡化**防爆音（TH13 没有，属加料）|
| **B（最忠实 TH13 硬切）** | 把灵界版 PCM 追加进 `thbgm.dat`（头 16B `ZWAV`；offset 是文件内偏移）+ `thbgm.fmt` 追加 0x34 记录，再复活 cmd9 | **fmt 装在 `th18.dat` 里** ⇒ 要重打包 **117 MB `th18.dat` + 430 MB `thbgm.dat`**；死 case9 要实测（它不更新 `th18:0x56d104`，要自己存/恢复）|
| **C（省事妥协）** | 灵界期间切到现成 `th128_08.wav`，或直接 `SetVolume(BGM, -10000)` 压低 | 便宜，但**不是该曲的灵界版** |

**最小验证实验**（选 A 前先做，不动正式代码）：
1. 运行期 `th18:0x48a5a0([th18:0x570484], -10000)` → 静音，再传 0 → 恢复（验证可调音量）；
2. 复活死 cmd9：安全帧入队 `th18:0x477a50(&th18:0x56ad80, 9, 0, "th128_08.wav")`，应切到 menu 曲且 `th18:0x56d104` 不变；
3. **第二路流**：构造 1 s PCM + 0x34 fmt，`th18:0x4898f0(...)` + `th18:0x48a440(my,0,1,0)` ⇒ 判据 = 引擎 BGM 与第二路**同时出声**、第二路音量可独立调、收尾无残留。

## 4. 纪律与流程（新会话必读）

- **构建/部署**：`cd mods/th18.v1.00a/card-expand/native && make check`（必须 rc=0）→ `MODKIT_DIR="/mnt/d/项目/幻想指南/18/th18_modkit" NO_GIT=1 make release` → `cd /home/nipporita/renkolab && bash local/sync_modkit_dll.sh`（**四路径同 md5 才算部署完成**；游戏在跑时 `thcrap/bin/...` 会被锁，别杀进程、让用户退游戏）。
- **断点**：新增 `BP_*` 必须同步 `native/sites.py` / `native/th18_card_expand.def` / `dllverify` 计数，且站点窗口 **≥5 字节**、不含相对寻址（历史上 3 字节站点被 thcrap 拒收 ⇒ SDK 门 FAIL ⇒ 新卡 id 被禁 ⇒ 玩家看到卡图变垃圾 + 编成槽消失）。
- **不要改 ECL**（除非用户点名）；文档改动后 `python3 tooling/check-docs.py` 必须过（跨版本文档里地址**必须带 `th13:`/`th18:` 前缀**）。
