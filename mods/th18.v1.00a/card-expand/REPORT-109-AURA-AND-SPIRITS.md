## §1 固灵结界（＝除霊オーラ）怎么画的

### §1.1 一句话

**每个角色自己的 `plNN.anm` 里的一条脚本**画出来：`sprite(-1)`（不用贴图、脚本自画）+ 一个形状图元 + 一组两色渐变 + `alpha(128)/alpha2(160)`；**半径 = `clamp(蓄力, 0, 200) × K_角色 / 100`**，20 帧 ease-4 长到目标；**绘制半径 = 判定半径**（同一帧写进 VM 缩放 `+0x54` 和判定半径 `+0x9c`）；关掉时走 `interruptLabel(1)` → `scaleTime(20, 4, 0, 0)` 收起再 delete。

### §1.4 脚本共性（逐条）

```
sprite(-1); layer(6);
<形状图元>;
color(0, 32, 128);      // 芯：深蓝
color2(64, 192, 255);   // 边：亮蓝
alpha(128); alpha2(160);
[angleVel(-0.017453292f, 0, -0.017453292f)]   // 多数 64 边形都会自转
stop(); interruptLabel(1);
scaleTime(20, 4, 0.0f, 0.0f);                 // 20 帧 ease-4 收到 0
+20: delete();
```

* **「圆为什么要自转」**（owner A8）：因为脚本里就写了 `angleVel(-1°/帧…)`；64 边形看不出边，纯属 ZUN 同一段脚本到处抄 ⇒ 复刻时照抄即可，也可以省。
* 颜色序按 **R,G,B**（一手：`color` 处理器 `0x4bf419` 的三字节落点 + `0x4c54f9` 把 `0x4ac` 整 dword 当 D3DCOLOR；另见 [`HANDOFF-109-STORM.md`](HANDOFF-109-STORM.md) §5）。
* 逐角色差异（一手）：燐 = 加算 + `color(255,255,255)`/`color2(255,0,0)` + `alpha(255)/alpha2(0)`，且收起时 `scaleTime(10,1,3.0f,1.0f)`（**放大**再消失）；PL16 用 `color2Time` 在 (244,128,255)↔(255,192,192) 之间来回；Marisa 的 `color`/`color2` 与其它角色**相反**（芯亮蓝、边深蓝）。

### §1.5 燐的特例（沈静化相关）

`AuraOrinInf` 槽7 = `FUN_0041ca40`：若 `aura+0xa0 != 0`（第二个圆心在场）且点落在以 `aura+0xd8` 为半径的第二圆内 ⇒ **`return -2`**（＝「打到核心」，与一般命中 `0/1` 区分）；否则回落到 `FUN_004d44e0(0, x, y, r)`（带朝向矩形测）。⇒ 「沈静化」的判定确实挂在 aura 上，且只有燐这一档有第二圆心。

### §1.6 另一层：`aura.anm`（共用贴图 `bullet/aura.png`）

`AuraCtrlInf` 自己持 `aura.anm`（`FUN_004e9960` 里 `FUN_004ce870(0x3e, "aura.anm")`）。其中 `script11`：

```
layer(34); sprite(-1); anchor(0,1); ins_617(1.0f, 4); pos(-1.0f,0,0);
scale(6,6); scale2(2,2);
color(255,255,255); alpha(255);      // 芯：白、实
color2(255,255,0);  alpha2(0);       // 边：黄、先透明
stop(); interruptLabel(4); alpha(255); alpha2(255); stop();   // → 黄边显现
interruptLabel(2); ... scale(9,1.8); ...
```

⇒ 「**白心 + 黄外圈**」这一层与 owner 对固灵结界的描述（A2）吻合。

**它什么时候出现（一手）**：`AuraCtrlInf` 的大任务 `FUN_004e79e0` 里——

1. 先把玩家位置抄到 `AuraCtrlInf+0x70`，调该角色 aura 对象的**槽2**（`(**(code**)(aura + 8))()` = 建/刷新角色那层）；
2. 然后 `FUN_004cb960(..., 0x1d, param_1+0x70, ...)` 在**同一位置**建第二个 VM（`aura.anm` **script29**，形态 = `sprite0..5` 每 3 帧一换的小动画）→ 句柄存 `AuraCtrlInf+0x64`；
3. 蓄力每涨过一档（`*(param_1+0x94)` 与 `FUN_0040b7a0()`/`FUN_0040b6a0()`/`FUN_0040b6e0()` 的档位比较）就把这个 VM **切到 script `0xb` = 11**（`FUN_004cb830(*(param_1+100), 0xb)`）⇒ **白心黄边圈是在蓄力达到档位后才出现的**，位置跟着玩家（`FUN_004cb3a0(*(AuraCtrlInf+0xcc)+4 + 0x68c)`）。

⇒ 固灵结界的完整观感 = **两层**：角色专属那层（§1.3 的 `plNN` 图元，半径随蓄力）+ `aura.anm` 的白/黄圈（**达到蓄力档位才叠上来**）。owner 的「白半透明+黄外发光」= 后者的 `script11`。

**`aura.anm` 的圈是 4 色 × 2 层**（一手，脚本 5–12 全是 `ins_617(1.0f, 4)` + `scale(6,6)`，只有颜色与混合不同）：

| 层 | 奇数脚本（普通 α）| 偶数脚本（`blendMode(1)` 加算）| 芯白 + 边色 |
| --- | --- | --- | --- |
| 5 / 6 | script5 | script6 | 白 + `(128,128,255)` 蓝紫 |
| 7 / 8 | script7 | script8 | 白 + `(128,0,255)` 紫 |
| 9 / 10 | script9 | script10 | 白 + `(255,0,0)` 红 |
| 11 / 12 | **script11** | script12 | 白 + `(255,255,0)` **黄** |

⇒ 每对 = 「白心 + 彩色边」的**柔光版 + 加算版**；`AuraCtrlInf` 在蓄力过档时切到 `0xb`(script11) ⇒ 黄的那对。其余 3 色（蓝紫/紫/红）应当是另外的状态/另一侧（❓ 未坐实，见 §1.7）。

### §1.7 ❓ 未收口

1. ✅ **已收**：`aura.anm script11` 的半径**不跟蓄力** —— `FUN_004e79e0` 里对那个 VM（`AuraCtrlInf+0x64`）只有 `FUN_004cb830(vm, 0xb)`（切脚本）和位置写入（`FUN_004cb3a0`），**没有任何 scale 写点**；脚本自己的 `scale(6,6)`（label2 → `scale(9,1.8)`）就是最终大小。
2. ✅ **已收（负向）**：`interruptLabel(1)` 的收起块**没有调用点**：`FUN_004cb7a0(vm, N)`（＝把 VM 及其子 VM 切到 interrupt label N，写 `vm+0x454`）在全 exe 只有 4 个调用者，都不在 aura 系统里 ⇒ 判「**收起块是死代码**，aura 结束时 VM 直接销毁」🟡（观感上就是直接消失）。
3. ❓ 部分角色的 `plNN.anm` 里还有第二个同类脚本（例：霊夢 `pl00` 除 15 还有 16/17/18 = 橙色版 + 两个子脚本），用途未定（另一个蓄力阶段？另一套玩法？）。
4. ❓ `AuraCtrlInf` 的 tick（`FUN_004e9740`）还会在 `y=456`（屏幕底部）建一个 `script0` 的 VM —— 形态上是**蓄力槽 HUD**，归属 anm 未坐实。

### §2.3 TH19 ↔ TH09 对照（一手）

TH09 的「霊」不是敌人，是**自机对象里的一个数组**：`Player__constructor`（`0x41f070`）里 `initialize_vector_without_destructor(zPlayer+0x30454, 0x2c4, 4, FUN_0041f060)` = 每侧 **4 个槽**（每槽 `0x2c4` B）。每槽 = {type, pos(3), 速度(3), active}。

| 项 | TH19（獣王園）| TH09（花映塚）|
| --- | --- | --- |
| 灵的本体 | ECL 敌人（外观由 `ins_303(0, N)` 指定 `enemy.anm` 脚本）| 代码对象（4 槽数组，`zPlayer+0x30454`）|
