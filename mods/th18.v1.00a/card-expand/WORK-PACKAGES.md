# WORK-PACKAGES —— 待办工单（给子 agent 分配用）

> **版本**：TH18 v1.00a（`th18.exe`，imagebase `0x400000`）。本文裸地址默认属该版本。
> **用途**：把「要干的事」切成**一个子 agent 一份**的工单：每包含目标、一手依据、涉及文件、验收、依赖与禁区。

> **分配纪律**（多 agent 同树作业的教训，见 [`AUDIT.md`](AUDIT.md) §BE-EG）：
> 1. **一个包一个 owner**：同一文件在磁盘上只有一个写者；包与包的文件集尽量不重叠。
> 2. **共享件改动必须登记**：`sdk.h` / `sdk.c` / `sdk_core.*` / `sdk/public.h` / `engine.h` / `sites.py` /
>    `Makefile` / `cards_def.c` / `patch/**` / `assets/**` ⇒ 往 `AUDIT.md` §BE 追加一行（`文件 → 改了什么 →
>    为什么 → 谁改的 → 怎么验证`）。

>    ⇒ 谁要加站点，先在 `GATES.md` §8 记账 + 改 `SITE_BUDGET`，**同一时间只允许一个包在做这件事**。
> 4. **生成物不许手改**：`patch/*.js`、`native/sites_gen.h` 由 `sites.py` 生成，改声明源后跑 `make gen`
>    （`make check` 会跑 `tools/gen_drift.py` 抓漂移）。
> 5. **发布只走** `make release`（先过 `release-check`：冻结/一致性）；发布后会自动记账。
