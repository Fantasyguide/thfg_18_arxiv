## 2. 坏在哪（**当前唯一结构性错误** ✗）

**症状**（owner 实跑 ✓）：「**框的左边线在大致屏幕的中线位置，高度不在最上边，里面没有填入 TH09 数字**」✓；框**中间透明** ✓（说明框切对了 ✓）。

**根因** ✓：HUD 的 VM 必须起在 **UI 列表**，我起在了**世界列表** ✗：

```c
/* native/sdk.h:245-254（一手 ✓）*/
/* UI 列表里起一个 VM（HUD 用；0x409670，世界列表版是 ce_anm_spawn）：
 *   pos = 实体坐标（NULL 也允许） */

/* 而我到处用的是：ce_anm_spawn(anm, script, layer) —— 世界列表 ✗ */
```
