1. **`git add -A` 会扫走别人的 WIP** —— 本工作区多人共用一个 index。★ 只 `git add <自己的路径>`；

2. **同一文件并发编辑**（`AUDIT.md` / `TUNING.md` / `CARDS.md` 最容易撞）—— 提交前先 `git diff --stat` 看一眼。
3. **`build/` 不入库** ⇒ 别用 git 判断「发布了没」。
4. **站点余量实际上为 0** ⇒ 任何「顺手加个 hook」都要先算账。
