// =====================================================================================
// 灵（card-expand id 109，**花映塚 × 獣王園 合成卡**）—— 自建真敌人载体
//
// ## 为什么是「自建真敌人」（owner 口径 10）
//
// 用户原话：「**灵的本体得建成类似于 th12 UFO 的敌人**」+（口径 8）「**th19 的灵和 th09 的灵
// 都得自己做**」⇒ 灵 = 我们自己的敌人（`ce_spawn_enemy()` 刷、能被自机弹打、能掉东西），
// **不借原版敌人、不借那两作的 ECL**。
//
// ## 这支子程序做什么
//
// · **外观**：`anmSelect(2)`（= `enemy.anm`）+ **`anmSetSprite(0, -1)` = 原版「拆槽」**
//   ⇒ 本体在 ECL 侧**隐形**，画面由卡侧的**跟随 VM** 画（照 112 的 UFO，一手 `th18:0x436bf6`）。
// · **运动**：★ 本子程序**不自己走** —— 位置由卡侧每帧写进 `%F2/%F3`（= `enemy+0x14d0/+0x14d4`；
//   一手 `Enemy__ecl_get_float_global_ptr` `th18:0x4387e0` 的分支表），
//   这里只 `movePosTime(1, 1, %F2, %F3)` 走过去（1 帧到点 ⇒ 连续跟随）。
//   先例 = 110 的绿妖精 `assets/ecl/green_extra.ecl.txt`（同一条通道）。
// · **体型**：逐条照抄 TH18 原生小妖精的体（`st01.ecl` 的 `GirlA01`：`setHurtbox(24,24)`、
//   `setHitbox(16,16)`），本卡略收小（❓ 自定：灵比妖精小一号 ⇒ 20 / 12）。
// · **血量 / 分数 / 掉落**都不在 ECL 里设：由卡侧的 `CE_SPAWN_*` 给
//   （`life` = 400、`score` = 0、`main_drop` = 0 —— 奖励全走卡侧的**灵力道具**，见口径 5）。
// · **不发弹**（❓ 自定）：灵是「可打的资源载体」，不是弹幕源；要它发弹得另写一段（一手在 TH19 侧）。
//
// ## 状态通道（★ 卡侧 ↔ ECL 唯一的通道，两个变量）
//
//   `%F2/%F3`（float，`enemy+0x14d0/+0x14d4`）= **本帧的目标坐标**（卡侧每帧写）。
//   `$I0`（int，`enemy+0x14b8`）= **状态**：`0` = 正常；`1` = **沈静化**；`999` = 卡侧喊走。
//
// ## 沈静化（口径 6；一手 TH19 `06-aura.md` §10）
//
// 一手 TH19 的做法（`th19:0x509030` 的 `-2` 分支）：跑 ECL 子 `GhostPureOrinDisable`
// ⇒ `@GhostPureHP_D` = `lifeSet(50 + I0*10)`（对照 enable 侧的 `400 + I0*400`）+ 停住 + 缓慢上浮；
// ⚠ 一手那个子程序**末尾没有 `delete()`**（`wait(100)` + `wait(60)` 后 `return`），
//   「自然成佛」的计时器在 v1.10c **没找到**（`06` §10.4）。
// 本卡的落地：卡侧把 `$I0` 写成 **1** ⇒ 本子程序走 `CESpirit109_calm`：`lifeSet(50)` + **停住**
//   （不再 `movePosTime`）；**成佛的 160 帧计时在卡侧**（`pofv_core.h` 的
//   `POFV_GHOST_CALM_FRAMES`，🟡 借一手那两个 `wait` 之和）—— 到点后卡侧把 `$I0` 写成 **999**
//   ⇒ 本子程序走 `CESpirit109_leave` 飞离自删。成佛**不算击破** ⇒ 不掉道具、不给分。
//   ⚠ 为什么计时放卡侧：ECL 侧的 `+160:` 版本**不可单测**；放卡侧就能用主机单测钉住
//     （`pofv_ghost_tick()` 的成佛名额 cap / 幂等沈静化，见 `tests/test_pofv_core.c` §I）。
//
// ## 离场
//
// `$I0 = 999`（卡侧在**沈静化成佛 / 删卡 / 一波结束**时喊）⇒ 飞向正上方 `delete()`：
//   离场**不算击破**、不给点（引擎的 `delete()` 不走死亡通道）。
//
// ## 一手与工具链
//
// · 合并：`assets/ecl/make_ufo_ecl.py` 把本文件与 `ufo.ecl.txt` / `green_extra.ecl.txt`
//   一起合进原生 `default.ecl` → `native/build/ecl/default.ecl`（`make ecl-ufo` 触发）；
//   发布靠 `native/release.py` 映射进 thcrap 常开的 patch-step3。
// · 子程序名 `CESpirit109` 必须**不与原生 `default.ecl` 重名**（合并脚本会当场报错）。
// =====================================================================================

// ## ★★★★ 2026-10-01 owner：「**动物灵有自己的运动模式在 th19 里面**」＋「**水獭灵应当斜着奔跑着下来**」
//   ＋「**你别重点是水獭，你其他的也抄过来**」⇒ 五种入场运动**逐字照抄 TH19 `default.ecl`** ✓
//   （一手在各个 `Ghost*Enable()` 里；`moveVel` 的 op 号 TH18/TH19 **同为 404** ✓ 所以能直接抄）：
//
//   | kind | 一手函数 | 一手入场（照抄值）|
//   | --- | --- | --- |
//   | 0 **狼** | `GhostWolfEnable` | `moveVel(1.5707964f, 1.1~1.5)` ⇒ **正下方 ~1.2** |
//   | 1 **水獭** | `GhostOtterEnable` | ★ `moveVel(0.3926991f…)` ↔ `moveVel(2.7488935f…)` **逐帧交替**、速度 **1.5** |
//   |   |   | `0.3926991 = +22.5°`、`2.7488935 = +157.5°` ⇒ **左下/右下交替着斜跑下来** ✓✓ |
//   | 2 **鷲** | `GhostEagleEnable` | 先 `moveVel(+π/2, 0)` 定住 → `moveVelTime(60,0,+π/2,3.5)` ⇒ **更快地向下** |
//   | 3 **ピュア霊** | `GhostPureEnable` | `moveVel(1.5707964f, 1.5f)` ⇒ **正下方 1.5** |
//   | 4 ❓ | （一手未定音）| 暂用与ピュア霊同值 ⇒ 登记 ❓ |
//
//   ★ 通道：卡侧把**种类**写进 **`$I1`**（`CE_ENEMY_ECL_I0 + 4` ✓）。
//   ★ 沈静化（`$I0 = 1`）：一手 `GhostDisableMove` = `moveVel(-1.5707964f, 0.02f)` +
//     `moveVelTime(200, 3, -1.5707964f, 2.0f)` ⇒ **缓慢上浮** ✓（本支取前者 ✓）。
//
void CESpirit109()
{
    anmSelect(2);
    anmSetSprite(0, -1);
    setHurtbox(20.0f, 20.0f);
    setHitbox(12.0f, 12.0f);
    // ★ 入场运动分派（照抄 TH19 的 `Ghost*Enable`，见文件头的表）
    unless ($I1 != 1) goto CESpirit109_otter @ 0;
    unless ($I1 != 2) goto CESpirit109_eagle @ 0;
    unless ($I1 != 3) goto CESpirit109_pure @ 0;
    // kind 0（狼，默认）：正下方 ~1.2
    moveVel(1.5707964f, 1.2f);
    goto CESpirit109_100 @ 0;
CESpirit109_otter:
    // ★ 水獭：+22.5° ↔ +157.5° **逐帧交替**（一手连发四次 `ins_404`）⇒「斜着奔跑着下来」✓
    moveVel(0.3926991f, 1.5f);
+1: //1
    moveVel(2.7488935f, 1.5f);
+1: //1
    moveVel(0.3926991f, 1.5f);
+1: //1
    moveVel(2.7488935f, 1.5f);
+1: //1
    goto CESpirit109_otter @ 0;
CESpirit109_eagle:
    moveVel(1.5707964f, 0.0f);
+1: //1
    moveVelTime(60, 0, 1.5707964f, 3.5f);
    goto CESpirit109_100 @ 0;
CESpirit109_pure:
    // kind 3/4：正下方 1.5（一手 `GhostPureEnable`）
    moveVel(1.5707964f, 1.5f);
CESpirit109_100:
    unless ($I0 != 999) goto CESpirit109_leave @ 0;
    unless ($I0 != 1) goto CESpirit109_calm @ 0;
    // ★★★★ 2026-10-01 修（实跑日志定案）：这里原来每帧 `movePosTime(1,1,%F2,%F3)` = 追着卡侧写的目标
    //   ⇒ **把入场那段一手的 `moveVel` 每帧覆盖掉** ✗✗ ⇒ 水獭实测「几乎直着下来」
    //     （日志：spawn (-96,16) → killed (-83,212)，Δx 只有 **+13** ✗）。
    //   ⇒ 一手 TH19 的动物霊**不追自机**（它们按自己的 `ins_404` 方向跑、攻击才瞄自机）✓
    //     ⇒ **去掉追踪**，速度只在入场时设一次（各 kind 的 `moveVel` ✓）。
+1: //1
    goto CESpirit109_100 @ 0;
CESpirit109_calm:
    lifeSet(50);
    moveVel(-1.5707964f, 0.02f);   /* ★ 一手 `GhostDisableMove`：沈静化 = **缓慢上浮** ✓ */
CESpirit109_calm_100:
    unless ($I0 != 999) goto CESpirit109_leave @ 0;
+1: //1
    goto CESpirit109_calm_100 @ 0;
CESpirit109_leave:
    moveVel(-1.5707964f, 3.0f);
+60: //60
    delete();
    return;
}
