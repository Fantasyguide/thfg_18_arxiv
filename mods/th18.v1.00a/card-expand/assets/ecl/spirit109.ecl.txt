// =====================================================================================
// 灵（card-expand id 109，**花映塚 × 獣王園 合成卡**）—— 自建真敌人载体
//
// ## 为什么是「自建真敌人」（owner 口径 10）
//
// 用户原话：「**灵的本体得建成类似于 th12 UFO 的敌人**」+（口径 8）「**th19 的灵和 th09 的灵
// 都得自己做**」⇒ 灵 = 我们自己的敌人（`ce_spawn_enemy()` 刷、能被自机弹打、能掉东西），
// **不借原版敌人、不借那两作的 ECL**。
//
// ## 这支子程序做什么
//
// · **外观**：`anmSelect(2)`（= `enemy.anm`）+ **`anmSetSprite(0, -1)` = 原版「拆槽」**
//   ⇒ 本体在 ECL 侧**隐形**，画面由卡侧的**跟随 VM** 画（照 112 的 UFO，一手 `th18:0x436bf6`）。
// · **运动**：★ 本子程序**不自己走** —— 位置由卡侧每帧写进 `%F2/%F3`（= `enemy+0x14d0/+0x14d4`；
//   一手 `Enemy__ecl_get_float_global_ptr` `th18:0x4387e0` 的分支表），
//   这里只 `movePosTime(1, 1, %F2, %F3)` 走过去（1 帧到点 ⇒ 连续跟随）。
//   先例 = 110 的绿妖精 `assets/ecl/green_extra.ecl.txt`（同一条通道）。
// · **体型**：逐条照抄 TH18 原生小妖精的体（`st01.ecl` 的 `GirlA01`：`setHurtbox(24,24)`、
//   `setHitbox(16,16)`），本卡略收小（❓ 自定：灵比妖精小一号 ⇒ 20 / 12）。
// · **血量 / 分数 / 掉落**都不在 ECL 里设：由卡侧的 `CE_SPAWN_*` 给
//   （`life` = 400、`score` = 0、`main_drop` = 0 —— 奖励全走卡侧的**灵力道具**，见口径 5）。
// · **不发弹**（❓ 自定）：灵是「可打的资源载体」，不是弹幕源；要它发弹得另写一段（一手在 TH19 侧）。
//
// ## 状态通道（★ 卡侧 ↔ ECL 唯一的通道，两个变量）
//
//   `%F2/%F3`（float，`enemy+0x14d0/+0x14d4`）= **本帧的目标坐标**（卡侧每帧写）。
//   `$I0`（int，`enemy+0x14b8`）= **状态**：`0` = 正常；`1` = **沈静化**；`999` = 卡侧喊走。
//
// ## 沈静化（口径 6；一手 TH19 `06-aura.md` §10）
//
// 一手 TH19 的做法（`th19:0x509030` 的 `-2` 分支）：跑 ECL 子 `GhostPureOrinDisable`
// ⇒ `@GhostPureHP_D` = `lifeSet(50 + I0*10)`（对照 enable 侧的 `400 + I0*400`）+ 停住 + 缓慢上浮；
// ⚠ 一手那个子程序**末尾没有 `delete()`**（`wait(100)` + `wait(60)` 后 `return`），
//   「自然成佛」的计时器在 v1.10c **没找到**（`06` §10.4）。
// 本卡照 owner 口径落地成：**停住 + 耐久骤降到 50 + 160 帧后 `delete()`（成佛）**
//   —— 160 = 一手那两个 `wait` 之和（🟡 借它的形），`delete()` 部分是本卡的**❓ 自定**
//   （成佛**不算击破** ⇒ 不掉道具、不给分；被玩家打死的才算击破）。
//
// ## 离场
//
// `$I0 = 999`（卡侧在**删卡 / 一波结束**时喊）⇒ 飞向正上方 `delete()`：
//   离场**不算击破**、不给点（引擎的 `delete()` 不走死亡通道）。
//
// ## 一手与工具链
//
// · 合并：`assets/ecl/make_ufo_ecl.py` 把本文件与 `ufo.ecl.txt` / `green_extra.ecl.txt`
//   一起合进原生 `default.ecl` → `native/build/ecl/default.ecl`（`make ecl-ufo` 触发）；
//   发布靠 `native/release.py` 映射进 thcrap 常开的 patch-step3。
// · 子程序名 `CESpirit109` 必须**不与原生 `default.ecl` 重名**（合并脚本会当场报错）。
// =====================================================================================

void CESpirit109()
{
    anmSelect(2);
    anmSetSprite(0, -1);
    setHurtbox(20.0f, 20.0f);
    setHitbox(12.0f, 12.0f);
CESpirit109_100:
    movePosTime(1, 1, %F2, %F3);
    unless ($I0 != 999) goto CESpirit109_leave @ 0;
    unless ($I0 != 1) goto CESpirit109_calm @ 0;
+1: //1
    goto CESpirit109_100 @ 0;
CESpirit109_calm:
    lifeSet(50);
+160: //160
    delete();
    return;
CESpirit109_leave:
    moveVel(-1.5707964f, 3.0f);
+60: //60
    delete();
    return;
}
