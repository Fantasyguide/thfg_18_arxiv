// =====================================================================================
// 「绿妖精」载体（card-expand id 110，风神录）—— **我们自己多刷一只绿的**，不碰原版妖精
//
// ## 为什么要有这支子程序（用户 2026-09-18 口径）
//
// 用户原话：「**有没有可能你给循环 +1？**」+「按照**几何形状**，每波多**一对**，或者多**一只**，你懂我意思」
// ⇒ 要的不是「把现有 24 只蓝妖精改成绿的」，而是**每波额外多出一两只绿妖精**（原作里纯信仰点掉落
//    本来就不多）。做法 = `ce_spawn_enemy()` 刷一只**我们自己的**敌人，它天生就是绿的。
//
// 为什么不用「改 ECL 循环计数 +1」：循环体只有**一处** `enmCreate("GirlBlueA01", …)`，所有迭代共用
// 同一个调用点 ⇒ 多刷出来的是**原色**妖精，引擎里没有任何字段能区分「我是多出来的那只」。
// 全量论证见 `REPORT-110-GREEN-FAIRY.md` §1.6。
//
// ## 这支子程序做什么 / 不做什么
//
// · **外观**：`anmSelect(2)`（`enemy.anm`）+ `anmSetMain(0, 10)` ⇒ `enemy.anm` 的**绿色变体**
//   （一手：同形异色四支 = sprite 0/12/24/36，逐 pose 掩码 IoU 1.000；绿那支是 sprite 24–35）。
//   ★ 顺带白拿一件事：`(N,S) = (2,10)` **已经在宿主表**（`cards/mof_big_faith_table.h`）里
//     ⇒ 它死亡时**自动**撒一颗大信仰点，`cards/mof.c` 一个字都不用加。
// · **入场**：`moveVel(%F0, %F1)` —— 卡侧在它出生时把**同波妖精的入场角/速度**采样了传进来
//   （`CE_SPAWN_ECL_F` = float[4] → `%F0..%F3`；一手先例 = 112 的 `assets/ecl/ufo.ecl.txt` 用 `$I0` 当控制通道）
//   ⇒ 它**沿着同一队形方向入场**，看起来是这一波里的一员，而不是凭空出现。
// · **运动/体型**：逐条照抄 TH18 原生小妖精的 `GirlA01` 体（`st01.ecl`：`setHurtbox(24.0f,24.0f)`、
//   `setHitbox(16.0f,16.0f)`、`moveVel(π/2, 1.0f)` → `wait(30)` → `moveAngleTime(120,1,0.61086524f)`
//   → `moveSpeedTime(300,1,2.5f)`），只把**第一条** `moveVel` 换成卡侧传进来的 `%F0/%F1`。
// · **不发弹**（`❓ 自定`，登记 `TUNING.md` §2.0h）：它只是「纯信仰点」载体；不发弹 ⇒ 不会额外打死玩家。
//   要让它像同波妖精一样发弹，把 `GirlA01` 体的 `@GirlA01_at()` 那段抄进来即可（一手在 `st01.ecl`）。
// · **血量/分数/掉落**都不在 ECL 里设：由卡侧的 `CE_SPAWN_*`（`life` / `score` / `main_drop`）给。
//   我们填 `main_drop = 0`（**纯**信仰点：死亡时只由卡侧撒一颗大信仰点，原生什么都不掉）。
// · **离场**：约 690 帧后飞向上方 `delete()`（照 112 的 UFO 离场写法）；离场**不算击破**、不给点
//   （引擎的 `delete()` 不走死亡通道）。
//
// ## 一手与工具链
//
// · 合并：`assets/ecl/make_ufo_ecl.py` 把本文件与 `ufo.ecl.txt` 一起**合进原生 `default.ecl`**
//   （TH18 每关 `st0X.ecl` 头部都有 `ecli { "default.ecl"; … }` ⇒ 全关共用；`make ecl-ufo` 触发）
//   → `native/build/ecl/default.ecl`；发布靠 `native/release.py:33` 映射进 thcrcap 常开的 patch-step3。
// · 子程序名 `CEGreenFairy` 必须**不与原生 `default.ecl` 重名**（合并脚本会当场报错）。

void CEGreenFairy()
{
    anmSelect(2);
    anmSetMain(0, 10);
    setHurtbox(24.0f, 24.0f);
    setHitbox(16.0f, 16.0f);
    moveVel(%F0, %F1);
+30: //30    入场 30 帧（与 GirlA01 同款节奏）
    moveAngleTime(120, 1, 1.5707964f);
    moveSpeedTime(300, 1, 2.5f);
+300: //330  转向/减速走完（照抄 GirlA01 体）
    moveSpeedTime(180, 1, 0.0f);
+180: //510  悬停一会儿（给玩家打它的时间）
    movePosTime(180, 1, (%RANDF2 * _f(32)) + %PLAYER_X2, -64.0f);
+180: //690  飞向上方离场（照 112 UFO 的离场写法）
    delete();
    return;
}
