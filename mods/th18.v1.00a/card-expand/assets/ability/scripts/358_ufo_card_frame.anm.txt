script script358 {
    // 112 星莲船 —— **满 B 掉落物的卡框层**（一手：TH18 场地卡道具 `abcard.anm` **script17** 逐条）
    //
    // ★★★ 2026-09-24 第 23 轮（owner 实跑）：「**缺少一个黑色的边框**」——
    //   比对基准是场上的 B 碎卡：它周围有一圈**细黑边**，而我们的满 B 没有。
    //   一手那圈边**不是卡图自带的**，而是卡道具那棵树里的**第三支子脚本**画的：
    //     `abcard.anm` **script17** = `sprite(sprite0); ins_431(1); randMode(1); type(1); layer(16);
    //                                   color(0, 32, 0); scale(0.3f, 0.3f);`
    //   其中 `sprite0` = entry0 **`ability/abframe.png`** —— 逐像素量过：64×80 的画布上
    //   **只有外圈 4 px 是白的**（1088 个可见像素全是 RGB(255,255,255)，其余 4032 个 alpha=0），
    //   乘上 `color(0,32,0)` ⇒ 那圈白边变**近黑** ✓ 就是 owner 要的黑边（0.3 倍率 ⇒ 屏显 1.2 px）。
    //
    //   ★ 上一轮（第 22 轮）我把这一支**跳过**了，理由是"卡图 64×80 alpha 满 255 全覆盖 ⇒ 卡框被
    //     整张盖住、一格都露不出来"。**错在哪**：我用 PIL 把它垫在深色背景上渲染，把**透明内部**
    //     看成了"深蓝实心块" ⇒ 误判成"实心卡框"。它实际是**空心环** ⇒ 画上去正好是卡沿那一圈边。
    //
    // **Δ（与一手一致的两条 + 三条本仓口径）**：
    //   · `sprite(sprite0)` → `@DROP_FRAME@`（= 原生 `abframe.png` sprite0 (0,0,64,80) 的 **1:1 切图**）。
    //   · `color(0, 32, 0)` / `scale(0.3f, 0.3f)` **一手原值照抄**（那圈边的颜色与粗细就是它们定的）。
    //   · `layer(16)` → **17**：一手三支子层都写 16、靠"先 `scriptNew` 的先画"排序（背光→卡面→卡框），
    //     我们写成 15/16/17 拿**同一个前后关系**（卡框必须在卡面**之上**才看得见边），不依赖创建顺序。
    //     ⚠ 三层都必须是**世界层**（3–19 = 游玩区相机 3）。
    //   · `ins_431(1)`（v8 未知 flag）不写，同脚本 301。
    //   · `pos(0,0,0)` 省略 —— 由父 VM（301）的 `entity_pos` 带，三层永远重合。
    sprite(@DROP_FRAME@);
    type(1);
    layer(17);                      /* ★ 卡面是 16 ⇒ 本层 17 = 画在卡面**之上**（那圈边才看得见）*/
    color(0, 32, 0);                /* ★ 一手原值：把白环乘成近黑（那圈"黑色的边框"就是它）*/
    scale(0.3f, 0.3f);              /* ★ 一手原值：64×80 × 0.3 = 19.2×24（与卡面同一倍率）*/
    stop();
}
