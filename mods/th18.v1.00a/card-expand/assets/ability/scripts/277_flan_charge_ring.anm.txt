// 地灵殿（id 111 · 咲夜×二小姐）的**消弹范围环** —— 用户口径（2026-09-16 逐字）：
//   「消弹范围应该是特效显示出来，类似于 th09 的固灵结界」。

// ══ ⚠ 2026-09-16 重做（上一版**实跑看不见**，用户报「shift蓄力依然啥都没有，只有消弹结果」）════
//   上一版：底本 TH17 `pl02.anm` script30（`drawPoly` 实心盘 + 减算 + 青蓝），卡侧 `scale = 0.4 + 1.6×蓄力进度`。
//   两处错，都已一手定案：
//     ① **`scale` 是「倍率」不是「半径」**：`drawPoly(R, n)` 写 `sprite_size.x = R`，绘制时
//        `最终尺寸 = sprite_size × scale`（`th16:0x4626eb` / `th16:0x468722`，见
//        `engine/anm/th16/09-drawing.md` §1.1/§4.4）。本脚本半径写 1.0f ⇒ **可见半径(px) = scale.x**。
//        上一版卡侧给 0.4 → 2.0 ⇒ 环只有 **0.4–2.0 px**，等于看不见（日志有
//        `signal: 二小姐·蓄力光环起 VM（id …，脚本 277，层 6）` ⇒ VM 确实起了，是尺寸错）。
//     ② **要画「一圈界线」就不该用 `drawPoly`**：它是**实心**多边形（本仓 120/121 的注就写「32 边形当实心圆」），
//        而 `drawPoly`(604) 才是**描边**、`drawRing`(611) 是**带厚度的环**。用户要的是界线。
//
// ══ 配方出处（一手，逐条）════════════════════════════════════════════════════════════════
//   底本 = **TH18 原生 `ability.anm` script35**（`local/th18.v1.00a/anm/ability/ability.anm.txt:1033`–`1042`，
//   「三环」族 script33/34/35 的最外圈；父 script33 由 `scriptNew(script35)` 起）：
//       script35 { blendMode(1); sprite(-1); layer(15); type(1); interruptLabel(2);
//                  drawPolyBorder(112.0f, 64); color(255, 32, 32);
//                +10: alphaTime(10, 0, 0);
//                +10: delete(); }
//   选它当底本的两条理由：
//     · **同一个游戏、同一份 anm 文件**（我们追加的脚本就编在 `ability.anm` 里），且它是**原生真实数据**
//       （`drawPoly` 在 TH18 有实跑数据，不像 `drawRing` 只在主菜单那条路上出现过 🟡）；
//     · 它是**环**（描边），正是「让人一眼看出消到哪」要的那种图元。
//   同族的 script33 还给了「环从中心长到满半径」的写法（`scale(0,0)` + `scaleTime(20,0,1,1)`），
//   **本脚本不抄它** —— 我们的半径是**卡侧逐帧给的真实清屏半径**，脚本里只要有一条 scale 插值在跑，
//   卡侧 `ce_anm_set_scale()` 就会被插值器盖掉（`native/sdk.h:330`）。
//
// ══ 逐条搬了什么、什么是 ❓ 自定 ═══════════════════════════════════════════════════════
//   · `sprite(-1)` / `blendMode(1)`（加算）/ `type(1)` / `drawPolyBorder(…, 64)` —— **逐条照抄 script35**
//     （64 边也是原值）。`sprite(-1)` ⇒ **零贴图消耗**，不新增 entry/sprite。
//   · 半径 `112.0f` → **`1.0f`**：**❓ 自定**（唯一的实质改动）。理由：半径必须**逐帧等于卡 111 的清屏半径**
//     （`2 × (自机判定半径 + 40.0)` = 86.00 px），写死在脚本里就会与 `signal_core.c` 的公式脱钩；
//     `drawPoly(1.0f, 32)` + 卡侧 `ce_anm_set_scale(id, R, R)` ⇒ 可见半径 = R px，
//     同一份数同时喂给「清屏判定 / 红染 / 本环」（口径见 `engine/card/th18/14-clear-range-barrier.md` §4.3）。
//   · `layer(15)` → **`layer(13)`**：**❓ 自定**。原生 15 只出现在主菜单那条路（`th18:0x465bc4`，
//     `MainMenu__on_draw`），世界列表里没有实证；本仓**实跑过的世界层**是 7（112 的描边环）/ 12 / 13。
//     取 **13** 的另一条理由：它和本卡的爆闪（脚本 278）**同层**，两者叠放顺序稳定。
//   · `color(255, 32, 32)` → **`color(120, 220, 255)`**：**❓ 自定**（纯观感：青蓝 = 「灵力结界」，
//     与上一版 TH17 蓄力光环同色系；原生那支是红的）。
//   · `alpha(64)` = **❓ 自定**（原生 script35 不写 `alpha` ⇒ 满 255；我们压到 1/4，免得 5 秒的环糊住视场）。
//     ⚠ 2026-09-16k 实跑前的可见性保险：提到 **110**（1px 描边 + 加算混合在亮背景上 1/4 透明度偏淡）——
//     这是**观感**旋钮，不是数值，想更淡就改回 64。
//   · 淡出：原生 script35 是 `+10: alphaTime(10,0,0)` → `+10: delete()`（**10 帧淡出 + 20 帧寿命**）。
//     我们改成 **20 帧淡出**（`alphaTime(20, 0, 0)` → `+20: delete()`）—— **❓ 自定**：
//     松手那一帧环正好等于清屏半径，淡出期间它**就是**「消到哪」的证据，10 帧（1/6 秒）太快看不清。
//   · `interruptLabel(2)` = **照抄 script35**（原生号）；`interruptLabel(1)` 是我们**额外**加的别名
//     （**❓ 自定**，与上一版同样的取舍：卡侧发几号不必猜，两个号都能淡出）。
//   · `pos(0.0f, 0.0f, 0.0f)` = 本仓写法（212/213/275 同款）：位置**由卡侧每帧给**
//     （绘制点 = 脚本 `pos` + 卡侧实体坐标，`CE_ANM_VM_POS` = `+0x5f0`，见 `engine/anm/th18/01-vm-instantiate.md` §3a）
//     ⇒ 脚本里不许写绝对 `pos`。归零只是防「模板 VM 带脏 pos」。
//
// ══ 卡侧契约（**逐帧驱动**）════════════════════════════════════════════════════════════
//   · 出生：**进入蓄力（`s->flandre.charge > 0`）那一帧**
//     `ce_anm_spawn(CE_ABILITY_ANM(), CE_ANM_ABILITY_SCRIPT_FLAN_CHARGE_RING, 13)`（第 3 参与 `layer(13)` 一致）。
//   · 位置：每帧 `ce_anm_set_pos(id, 玩家 x, y, z)`。
//   · 半径：每帧 `ce_anm_set_scale(id, R, R)`，`R` = `signal_flandre_cancel_radius_x100(自机判定半径×100) / 100`

//   · 收尾：松手 / 中弹打断 / 删卡三条路都要收 —— `ce_anm_interrupt(id, 1)`（20 帧淡出后脚本自删）
//     或 `ce_anm_delete(id)`（`METHOD.md` 的长持续效果铁律：删卡发生在商店里，那一刻只有 `on_delete` 跑得到）。
// ★★ 2026-09-16m 图元改正（**実跑可见性**）：`drawPolyBorder`(605) 换回 **`drawPoly`(604)**，

//   理由：605（描边）在 TH18 **世界列表里没有一条实跑可见的实例**（原生 script35 只在主菜单那条路上），

    sprite(-1);

    alpha2(110);
