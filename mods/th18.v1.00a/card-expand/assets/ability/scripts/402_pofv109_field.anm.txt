script script402 {
    // 109 合成卡「**场**」（暴风 / 蓄力攻击红圈）的视觉 —— 卡侧**跟随 VM**、每个活着的场一台。
    //
    // ══ ★ 2026-10-01 新增：owner 实跑「**暴风缺少UI**」═══════════════════════════════════
    //   此前暴风**只有 `ce_damage_rect` + 消弹，一点画面都没有** ✗ ⇒ 玩家看到的是
    //   「**无缘无故**掉血/敌人死」（因为看不见场在哪）。本次补上。
    //
    // ══ 形状是一手 ═════════════════════════════════════════════════════════════════════
    //   · 场 = **逐帧扩张的圆**：`pofv_storm_t` 的 `r0`（起始半径）/ `dr`（每帧增量）就是它的规格
    //     （owner 口径：「**消弹圈是逐帧扩张的场**」；暴风与 CA 红圈共用这个场池，只是 r0/dr 不同）。
    //   · **画法**照本卡既有的两处同族（`373_pofv109_aura.anm.txt` / `375_pofv109_shield.anm.txt`）：
    //     `sprite(-1)` + **程序化** `drawPoly(1.0f, 32)` 单位圆盘，半径由卡侧每帧写 `scale`。
    //     （那两处的一手依据是 TH19 的原版脚本首行就是 `sprite(-1)`、形状全靠 `drawPoly` 一族；
    //       本脚本沿用同一处置，卡侧 = `storm_vm_sync()`。）
    //   · ❓ **配色是自定的**：一手 TH09 爆风的**精确图元/贴图本仓还没定位到**（我查过 `etama*.png`
    //     那几张：etama3 = "Border of Life" 字、etama5 = 白光盘，都不是那一圈）⇒
    //     先按代码里一直用的叫法「**蓝圈**」给一组蓝色（暴风），红圈（CA）由卡侧 `ce_anm_set_color`
    //     染成红 —— 两种场共用这一支脚本、**只靠卡侧染色区分** ✓。
    //   ⚠ 脚本里**不写** `scaleTime`（会与卡侧每帧的 `set_scale` 打架，见 `sdk.h` 的注释）。
        // ★★★ 2026-10-01 三改（owner）：「**你的暴风的样式既不是 th09 也不是 th19，反而像是 th19 固灵结界**」＋
    //   「th19 的暴风样式是**偏黑色偏褐色**，可能有点类似于你目前的样式，但是**以减去的混合模式**画上去的」
    //   ⇒ 改成 dark + **减去混合** ✓ —— 不再用白/蓝加算（那一路看着就是结界 ✗）。
    //   ⚠ 我扫过 `th19.dat` 的 `effect.anm`（187 个脚本）没找到「暗色 + blendMode(2)」那一条
    //     ⇒ **按 owner 的描述实现**（颜色取黑褐、混合模式取减去），如实登记为「按描述复刻」。
    // ★★★ 2026-10-01 四改（owner 纠了我的**搜索方向**）：「**你找的是暗色+blendMode(2)，
    //   不应该找的是亮色+blendMode(2) 吗**」——对 ✓：
    //     减去混合是**把画上去的光减掉** ⇒ **源要画亮色**，减出来的结果才是暗的 ✓；
    //     而且用**暖白**（R 满、G/B 略低）减出来会**偏褐**，冷白只会减成中性黑 ✗。
    //   ⇒ 本脚本改成 **暖白 + `blendMode(2)`**：观感 = 暗色偏褐 ✓（与 owner 描述一致）。
    //   ⚠ 我按「亮色 + `blendMode(2)`」重扫过 TH19：`effect.anm` 里 `blendMode(2)` 只有 4 个
    //     （script3 = `drawPoly(20,16)` 青、script24 = 绿，都是**小**圆 ✗），
    //     `bullet/enemy/pl00/aura/front.anm` 里**没有**「blendMode(2) + 大 drawPoly」✗
    //     ⇒ TH19 那个暴风**不在 anm 里**（很可能是**代码画的**，和 hits 计数器一样）✓。
    //     所以这里仍是**按 owner 的描述**复刻（暖白 + 减去），不是照抄某个脚本。
    sprite(-1);
    drawPoly(1.0f, 32);
    blendMode(2);                  // ★ 减去混合（0=普通 1=加算 2=减去）
    // ★★★ 2026-10-01 五改（owner）：「**暴风我看见的是纯黑色，一手中间得有透明度的，也不怎么黑**」
    //   ⇒ 减去混合下 **alpha 越大减得越狠 = 越黑** ⇒ 把**内层 alpha 降到很低**（中间透明 ✓）、
    //     外层给中档（边缘稍实 ✓），颜色也再淡一点 ⇒ 不再是一块纯黑 ✗。
    color(255, 240, 210);          // 内层：暖白（减出来偏褐）
    alpha(60);                     // ★ 很低 ⇒ **中间是透的** ✓
    color2(255, 228, 186);
    alpha2(130);                   // 外层：中档（`不怎么黑` ✓）
    stop();
}
