// ══ 一手：这台特效是谁 ═══════════════════════════════════════════════════════════════════
//   · 触发点：TH10 满 P 那一帧的全场转换循环 `th10:0x41ba50`（`ItemManager::on_tick__body` 尾部

//     清在用标志 + `spawn_item(type=9, pos=道具自己的位置, 角 −π/2, 速 2.2)`（helper `0x41bb00`），
//     然后 **`0x448db0(anm_obj, &item.pos, 0x189)`**。

//     命名）alloc 一台 VM（位置 float3 写 `+0x340`、脚本指针写 `+0x38c`/`+0x390`、标志写 `+0x35c`），
//     并用**第 3 个实参查脚本表** `[anmgr+0x11c][id*4]`（该表 ~400 项）
//     ⇒ `0x189` = **anm 脚本号**（**不是 SE id** —— 我们旧注写成「逐颗播音」是误读）。
//   · **原版转换静音**（一手）：TH10 的 SE 播放器是 `0x43dc90`（`ecx = SOUND_MANAGER 0x492590`），
//     而转换循环 `0x41ba50`–`0x41baef` 与 spawn helper `0x41bb00` 里**一次都没调它**

//     两者函数体都不引用 `SOUND_MANAGER 0x4c3e80`）⇒ 卡侧那颗借来的 `se_powerup` 已撤。
//   · 脚本号 0x189 = 393 = **`bullet.anm` script393**（复跑：`local/vendor/thtk/build/thanm/thanm -l 10
