script script279 {
// 灵击（**110 风神录 / 111 地灵殿**共用）的**消弹范围环** —— 把「这一发灵击到底消到哪」画出来。
//
// 用户口径（2026-09-16 逐字）：「**灵击依然没有特效**」（此前 110/111 的灵击只有消弹与伤害、零视觉）。
//
// ══ 这是什么、不是什么（**先把话说清楚，免得被当成复刻**）══════════════════════════════
//   · **半径 = ✅ 一手**：TH10 的灵击半径**就是**它那支 anm VM 的 `scale.y` ——
//     `Bomb::on_tick` 每帧 `[bomb+0x3c] = vm.scale.y`（`th10:0x40580e` / `th10:0x405813`，
//     见 `engine/player/th10/01-bomb-full-chain.md` §3），曲线 = `bullet.anm` **script400**
//     （灵梦）= `scale(16,16)` + `scaleTime(120, 6, 16.0 → 160.0)`；魔理沙 script407 → 112.0；
//     符卡中 script441 → 64.0。我们的卡 110 **已经在复刻这条曲线**
//     （`mof_core_bomb_radius_centi()`：16.00 → 目标、120 帧线性、其后保持）。
//     111 侧的一手是另一条：TH11 的 bomb 是**逐帧长大**的圈（`[bomb+0x490] += [+0x494]`，
//     初值 32.0 / 每帧 +10.0，`th11:0x45ded6`；`engine/player/th11/01-bomb-and-lifegrags.md`）。
//   · **图元 = ❓ 自定**：TH10 那四支环/柱（`bullet.anm` script394–397）画的是
//     `sprite(sprite362)`（etama3.png 的 14×128 竖条）+ `texCircle(32)`（v8 的 opcode **600**）——
//     也就是「把一条渐变竖条弯成圆圈」，半径同样吃 `scale`。本轮**没有移植那条竖条贴图**，
//     改用本仓**已实跑过**的 `drawPoly`(604)（223/229/230 先例）画同一圈。
//     ⇒ 「半径可编程的一圈」这件事与原生同构，**画法不同**；要完全对齐就得再抠 sprite362。
//
// ══ 配方出处（一手，逐条）════════════════════════════════════════════════════════════════
//   底本 = **TH18 原生 `ability.anm` script35**（同一份 anm 文件里「三环」族的最外圈）：
//       script35 { blendMode(1); sprite(-1); layer(15); type(1); interruptLabel(2);
//                  drawPolyBorder(112.0f, 64); color(255, 32, 32);
//                +10: alphaTime(10, 0, 0);
//                +10: delete(); }
//   `sprite(-1)`（零贴图消耗）/ `blendMode(1)`（加算）/ `type(1)` / 64 边 —— **逐条照抄**。
//   ⚠ 与脚本 277（111 二小姐的范围环）**同一套取舍**：277 是同一个「半径由卡侧给」的写法，
//     两条脚本**故意分开**，因为它们描述的是两件事（一个是特技的范围、一个是灵击的范围）。
//
// ══ ❓ 自定项（逐条给理由）══════════════════════════════════════════════════════════════
//   · 半径 `112.0f` → **`1.0f`**：一手「可见半径(px) = 参数 × `scale`」（`th16:0x4626eb` /
//     `th16:0x468722`：最终尺寸 = `sprite_size × scale`）⇒ 半径**由卡侧逐帧给**
//     （110 = 它自己的灵击半径；111 = TH11 的 `32 + 10×帧` 曲线）。
//     脚本里**不许**写 `scale`/`scaleTime`，否则会被插值器盖掉卡侧写值（`native/sdk.h:330`）。
//   · `layer(15)` → **`layer(13)`**：原生 15 只在主菜单那条路出现（`th18:0x465bc4`），
//     世界列表无实证；本仓实跑过的世界层是 7 / 12 / 13。取 13 也与 277 / 278 一致。
//   · `color(255,32,32)` → **`color(200, 235, 255)`**、`alpha(96)` —— 纯观感（原生红、满 255）；
//     灵击是「灵力冲击」⇒ 用冷白蓝，且在弹幕里压到 3/8 免得糊住视场。
//   · 淡出 = `interruptLabel(1)` → **20 帧淡出后自删**（原生 script35 是 10+10=20 帧寿命）；
//     加 `interruptLabel(2)` 作同义别名（**❓ 自定**：卡侧发几号不必猜）。
//   · **本脚本自己不会死**（`stop()` 之后只画）：寿命**完全由卡侧定**（110 = 120 帧成长 + 淡出；
//     111 = 75 帧成长 + 淡出）—— 这样「环 = 那一发的真实半径曲线」逐帧成立。
//
// ══ 卡侧契约（**逐帧驱动**）════════════════════════════════════════════════════════════
//   · 出生：`ce_anm_spawn(CE_ABILITY_ANM(), CE_ANM_ABILITY_SCRIPT_BOMB_CLEAR_RING, 13)`（第 3 参 = 层 13）
//     + 写一次 `ce_anm_set_pos(id, 灵击中心 x,y,z)`。
//   · 半径：**每帧** `ce_anm_set_scale(id, R_px, R_px)`；中心会动（110 的灵击中心每帧上移）⇒
//     位置也要每帧写。
//   · 收尾：`ce_anm_interrupt(id, 1)`（20 帧淡出，脚本自删）。
//     ⚠ 再保险：卡侧淡出后 30 帧仍能拿到 VM 就 `ce_anm_delete(id)` 硬删
//       （`METHOD.md` 的长持续效果铁律：删卡发生在商店里，那一刻只有 `on_delete` 跑得到）。
// ★★ 2026-09-16m 图元改正（**実跑可见性**）：`drawPolyBorder`(605) 换回 **`drawPoly`(604)**，
//   并补齐 `zWriteDisable(1)` / `color2` / `alpha2` —— 整段静态属性**照抄本仓实跑确认看得见的
//   `120_season_ring_out.anm.txt` / `121_season_ring_in.anm.txt`**（116 季节解放的双圈，用户实跑见过）。
//   理由：605（描边）在 TH18 **世界列表里没有一条实跑可见的实例**（原生 script35 只在主菜单那条路上），
//   而用户两次实跑都报「看不见」（2026-09-16「shift蓄力依然啥都没有」/「灵击缺少特效」）
//   ⇒ 不再赌 605，改用 604（= 半径 1.0 的 32 边形**实心盘** + 卡侧 scale = px 半径，与 120/121 同法）。
//   ⚠ 代价：从「一圈界线」变成「一块半透明的圆盘」；`alpha2` 与 `color2` 同时写上是为了
//   `colorMode` 走哪一路都画得出来（`native/sdk.h` 的「两路」注释）。
    sprite(-1);
    layer(13);
    zWriteDisable(1);            // ★ 2026-09-16m：照 120/121（实跑确认可见）补上
    drawPoly(1.0f, 32);          // ★ 半径 1.0 ⇒ 可见半径(px) = 卡侧 scale.x（一手：sprite_size × scale）
    blendMode(1);
    color(150, 215, 255);
    color2(150, 215, 255);
    alpha(72);   // ★ 2026-09-16o：用户实跑「th10 的灵击比这个**更浅**」⇒ 110 → 72
    alpha2(72);
    pos(0.0f, 0.0f, 0.0f);       // 归零：位置由卡侧每帧 ce_anm_set_pos 给（见上面的契约）
    stop();
    interruptLabel(1);           // ★ 卡侧收尾用：20 帧淡出 → 自删
    alphaTime(20, 0, 0);
    alpha2Time(20, 0, 0);
+20: // 20
    delete();
    interruptLabel(2);           // ★ ❓ 自定别名（与中断 1 同义）
    alphaTime(20, 0, 0);
    alpha2Time(20, 0, 0);
+20: // 20
    delete();
}
