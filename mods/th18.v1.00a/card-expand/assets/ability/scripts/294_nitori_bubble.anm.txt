script script294 {
// 荷取（河童）罩子的**水泡**（卡 111，魔理沙侧）—— TH11 `pl01.anm` **script58** 的逐条移植。
//
// 用户口径（2026-09-16 逐字）：
//   「放B是消弹，给一个**防护罩（有贴图特效）**，只要防护罩不撞认为是 no miss。
//     然后加强一下吧，对于**原生的B**，河童特效也会引入**不撞破罩子 no miss 和一个罩子**」
//
// ══ 这是什么（一手，逐条）══════════════════════════════════════════════════════════════
//   TH11 的 `Bomb::start__marisa_c`（`th11:0x407680`）在放 B 那一帧起一支特效，之后
//   **每帧把它钉在自机身上**（`th11:0x407866`–`0x407892`：`bomb+0x484..0x48c = player.pos` →
//   `th11:0x407892 call 0x456430` = `AnmVm::set_entity_pos_plus_ecl_origin`）：
//     | 一手 | 值 |
//     | --- | --- |
//     | 脚本 / 层 | **script58**（`th11:0x4076ec push 0x3a`）/ **layer 22**（`th11:0x4076e7 push 0x16`）|
//     | 贴图 | `sprite(sprite76)` = `pl01.anm` entry3 `pl01c.png` 的 (1, 1, 254, 254) ⇒ `@NITORI_BUBBLE@` |
//     | 寿命 | **920 帧**（脚本 `+900:` 后 `delete()`；屏幕亮度曲线的收尾点同帧，`th11:0x40781e`）|
//     | 破罩 | 被打中时 `th11:0x40793d call 0x4070e0`（`anm_trigger_leave_by_id`）⇒ 走 `case(1)` 那支 |
//   ⚠ `case(1)`（TH11 = anm v7）在本仓的 v8 语法里写作 **`interruptLabel(1)`**（同一指令，
//     本仓一律这么写，例：脚本 279/293）。
//
// ══ 逐条搬了什么（**正文与 TH11 原文一一对应**，顺序也一致）════════════════════════════
//   `layer(22)` → **`layer(13)`** ／ `blendMode(1)` ／ `type(1)` ／ `sprite(sprite76)`
//   ／ `angleVel(0.0f, 0.0f, -0.05235988f)`（= **−3°/帧**自转）／ `alpha(0)` + `alphaTime(10, 0, 255)`
//   ／ `scale(0.0f, 0.0f)` + `scaleTime(20, 0, 1.0f, 1.0f)`（20 帧胀到 1.0）
//   ／ `+20:` `scaleTime(900, 0, 0.1f, 0.1f)`（再用 900 帧缩到 0.1）／ `+900:`（第 920 帧）`delete()`
//   ／ `interruptLabel(1)`：`scaleTime(30, 0, 3.0f, 3.0f)` + `alphaTime(30, 1, 0)` ／ `+30:` `delete()`。
//
// ══ ❓ 自定项（逐条给理由；本仓纪律：不许把自定包装成「复刻」）══════════════════════════
//   · `layer(22)` → **`layer(13)`**：22 是 TH11 的世界列表号，TH18 的层号体系不同；13 = 本仓
//     **实跑确认可见**的世界层（110/111 的灵击环 279/293、UFO 令牌都是 13）。
//   · `pos` 归零、**位置由卡侧每帧写**（`ce_anm_set_pos`）：一手也是「每帧把泡钉在自机身上」，
//     区别只是那件事在 TH11 由 `Bomb::on_tick` 做、在我们这里由卡的 tick 做。
//   · **脚本里不许加 `scale`/`scaleTime` 以外的插值器**，卡侧也**不写** `scale`
//     —— 泡的尺寸语义 = `sprite_size × scale`（一手 `th16:0x4626eb` / `0x468722`），
//     这里的 `scaleTime` 是**原生曲线本体**，谁都别盖它（`native/sdk.h:330` 那条纪律的反面用法）。
//   · `alphaTime(10, 0, 255)` 的 **255 照抄**（原生就是 255）—— 用户实跑若觉得 254 px 的泡糊视场，
//     降的应该是这一条的终值，**不是尺寸**（尺寸与「泡＝自机大小的保护圈」这件事绑定）。
//
// ══ ★★ 2026-09-16u：alpha / scale 的两条曲线**搬到卡侧**了（原因见下），本脚本只管图元与破罩
//
//   用户口径（逐字）：「**B 的无敌时间不算做罩子的持续时间**，此时撞任何弹幕都应该认为是没撞，
//   **包括其他的无敌、类无敌情况**」⇒ 罩子寿命按**暴露帧**计（无敌的那一帧不推进）。
//   ⚠ 而 VM 自己的时间线**没法暂停**（anm 的时间标签是绝对的：泡要是在第 200 帧被打掉，
//     后面那个 `+900: delete()` 是**第 920 帧**的绝对时刻，不是「再等 900 帧」）⇒
//     一手那三条 `alphaTime(10,0,255)` / `scaleTime(20,0,1,1)` / `scaleTime(900,0,0.1,0.1)`
//     在本脚本里**删掉**，改成卡侧按暴露年龄逐帧求值的**逐条等价式**
//     （`signal_nitori_bubble_alpha()` / `signal_nitori_bubble_scale()`，三个数与终点全是一手）。
//   ⚠ 因此本脚本**不许**再写 `alpha`/`alphaTime`/`scale`/`scaleTime`（除了破罩那一支）——
//     会与卡侧每帧的写入打架（`native/sdk.h:330`）。
//
// ══ 卡侧契约（`native/cards/signal.c` 的 `signal_shield_*`）════════════════════════════
//   · 出生：`ce_anm_spawn(CE_ABILITY_ANM(), CE_ANM_ABILITY_SCRIPT_NITORI_BUBBLE, 13)` + 写一次 pos；
//     之后**每帧**写 pos（泡跟着自机走）+ 按暴露年龄写 scale（`ce_anm_set_scale`）与 alpha
//     （`ce_anm_set_color` 的 A 字节）。
//   · 破罩：`ce_anm_interrupt(id, 1)` ⇒ 本脚本自演 30 帧的胀大淡出后自删（= 一手 `0x4070e0`）；
//     卡侧在 30 帧后**显式删**（一手 `th11:0x407980`）。
//   · 寿命尽头（= 暴露年龄满 920 帧）：**由卡侧删**（本脚本不再自己走到 `delete()`）。
//   · 收尾：删卡 / 换关 / 局末由卡侧 `signal_shield_kill()` 收（长持续效果铁律）。
    layer(13);
    blendMode(1);
    type(1);
    sprite(@NITORI_BUBBLE@);
    // ★★ 2026-09-16u：一手的 `angleVel(0.0f, 0.0f, -0.05235988f)`（−3°/帧 = **逆时针**）**搬到卡侧**
    //   （`ce_anm_set_rotation`，用户口径「持续中的罩子应当是逆时针旋转」）：
    //   `stop()` 之后脚本的角速度还有没有效没有实证 ⇒ 卡侧写死最稳。
    zWriteDisable(1);                     // 照 279 / 120 / 121（本仓实跑确认看得见的那几条）
    alpha(255);                           // 卡侧每帧改写（初值只为「不是 0」）
    scale(0.0f, 0.0f);                    // 卡侧每帧改写（第 0 帧就是 0）
    pos(0.0f, 0.0f, 0.0f);                // 归零：位置由卡侧每帧给（见上面的契约）
    stop();                               // ★ 2026-09-16u：不再自己走时间线（曲线在卡侧）
    interruptLabel(1);                    // 破罩（一手 `case(1)`）：30 帧胀到 3 倍 + 淡出后自删
    scaleTime(30, 0, 3.0f, 3.0f);         // 一手：`scaleTime(30, 0, 3.0f, 3.0f)`
    alphaTime(30, 1, 0);                  // 一手：`alphaTime(30, 1, 0)`
+30: // 破罩 30 帧
    delete();
}
