## 0. 一句话

**`228` 的两处改动** ⇒ 就是领域扇形：`scale` 改成 `(2R, R)`（内径 0 = 实心 ✓）、`rotation.x` 改成**张角**（而不是 `fill×2π`）、`rotation.z` 改成**朝向**、颜色改单色 ✓。

## 1. 原型（112 的弧）到底怎么画

* `sprite(-1)` ✓ 无贴图 ⇒ **纯几何** ✓；图元 = **`texArcEven(n)`**（opcode **601** ✓，`local/vendor/eclmap/anmmap/v8.anmm` ✓）⇒ **以 `rotation.z` 为中心向两侧各展开 `rotation.x/2`** ✓（TH12/TH18 一手见 `228_ufo_gauge_arc.anm.txt` 注释 ④⑤⑥ 与 `ufo.c:3017` 一带 ✓）。
* 几何语义（`engine/anm/th16/09-drawing.md` §3.2 已逐条解完 ✓）：
  * `rotation.x`（`vm+0x38`）= **总弧角（张角）** ✓
  * `rotation.z`（`vm+0x40`）= **基准角（朝向）** ✓
  * `scale.y`（`vm+0x58`）= **中心半径** ✓，`scale.x` = **环宽** ✓
    ⇒ `r_out = scale.y + scale.x/2`、`r_in = scale.y − scale.x/2`
    ⇒ ★ **`scale.x = 2 × scale.y` ⇒ `r_in = 0` ⇒ 内径为 0 = 实心扇形** ✓
  * `n`（`texArcEven` 的参数）= **分段数** ✓（越大弧越圆 ✓）
* ⚠ 命名坑：map 里的正式名是 **`texArcEven`(601) / `texArc`(602) / `texCircle`(600)** ✓；
  `textureArcEven` 这种写法 **不在 map 里** ⇒ `unknown mnemonic`（你的 `406_pofv109_aura_sakuya.anm.txt:20` 就踩过 ✓）。

## 6. ⚠「半透明怎么也消不掉」的两个真凶（2026-10-06 静态定案）

### 6.1 加算 `blendMode(1)` **本质上不遮挡背景** ⇒ 观感永远是“透的” ✗

本仓一手（[`engine/anm/th18/07-blendmode-rgb-only-alpha-is-sa.md`](../../../engine/anm/th18/07-blendmode-rgb-only-alpha-is-sa.md)）：
TH18 anm **分离 alpha 混合恒开** ⇒ `Aa' = ONE·Sa + ZERO·Da = Sa`，**与 `blendMode` 无关**；
`blendMode(n)` **只决定 RGB** ✓。

⇒ ⇒ 在 **`blendMode(1)`（加算）** 下，弧只把自己**加**到背景上 ⇒ **不可能遮挡背后的东西** ✗
⇒ ⇒ 这就是「固有透明度」的真身 ✓ —— **RGBA 的 A 写多少都没用** ✗（加算的 RGB 里根本不带 A 的作用 ✓）。
⇒ **解法**：`blendMode(0)`（普通 α 混合）✓ + `Sa = 255` ✓ ⇒ 才真正不透明 ✓。

（顺带：`blendMode` 的“亮/暗背景差异”也源于此 ✓ —— 加算在暗底上只显自己的颜色 ✓、在亮底上直接饱和 ✓。）

### 6.2 弧族的取色寄存器：**可能是 `color_2`，不是 `color_1`** ✗

`engine/anm/th16/09-drawing.md` §3.2（弧族 `texArcEven`/`texArc` ✓）一手：

> **颜色**：`(flags_lo & 0x60000)` 非 0 取 **`color_2`（`+0x524`）**、否则取 `color_1`（`+0x520`）——
> ★ **内外两个顶点用的是同一个颜色**，本族**没有**内外渐变。

⇒ ⇒ 只调 `ce_anm_set_color`（= **`color_1`** ✓）时，若那两位标志被脚本的 `color2()` 置上了，
**写进去的 RGBA 根本没上屏** ✗ ⇒ 视觉“怎么改都一样” ✓。
⇒ **解法**：颜色/α 要**两个寄存器都写** ⇒ `ce_anm_set_color(id, rgba)` **+ `ce_anm_set_color2(id, rgba)`** ✓
（SDK 注释自己写着「`ce_anm_set_color` 只写 `color_1`」✓）。
