## 3. 目标机制

```
按住 C（电平 CE_INPUT_HELD() & 0x400）
   ├─ 固灵结界展开（常驻判定；形状取一套几何）
   └─ 蓄力推进 → 4 档（可放档 = min(档, 槽)）
场上：消弹 / 击破 / 结界碰敌弹  →  掉「灵力道具」  →  拾取  →  攻击槽 +点
松开 C → 放档（1..min(档, 槽)）：消弹圈 + 无敌 + 伤害（沿用现有 `ca_effect`）
结界对「灵」：沈静化（停住 + 耐久骤降 → 成佛）
```

灵 = 我们自己的 ECL 子程序（TH19 三族：狼/獺/鷲 ＋ TH09 的霊）+ 卡侧跟随 VM 画图
灵的行为：漂浮/索敌 → 被击破 → 掉灵力道具；被固灵结界命中 → 沈静化（停住 + 耐久骤降）→ 成佛
