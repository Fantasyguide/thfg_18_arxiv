#### §th12-P3 —— 三件的一手与改法（2026-09-22，工单 `WORK-PACKAGES.md` §0 P3）

> 全文（逐指令 / 常量 / 三处互证）在 [`engine/ufo/th12/01-ufo-system.md`](../../../engine/ufo/th12/01-ufo-system.md) §10b，

  ⇒ 那套空间里场地占 x∈[32,416] / y∈[16,464]）⇒ **场地相对** x 20/41/62、y 440，折到 TH18 表面 =
  **296/338/380 × 912**（生成器 `X_SHIFT_640` 0 → **96**）。旧值 104/146/188 是「把世界坐标当屏幕 px」，

  顺带两处表现订正：贴图**居中**贴进 32×16 画布（`anchor(0,0)` = 锚心，左上角贴会整排左偏 8 表面 px）、
  闪烁相位改用 **UFO 自己的年龄**（`th12:0x44a2e0` 的 `%16==1`；旧版用全局游玩帧是猜的）、
  离场时补发四态中断（`th12:0x44a357` 的 `FUN_004214b0(gui,−1)`）。
  ⚠ **口径冲突**：本块（表面 272..404 / 896..928）与 **116**（263..365 / 888..920）、
  **117**（257..449 / 876..924）的 HUD 块横向重叠 ⇒ 两条路你挑（见 `TUNING.md` §2.0x 末段）。
- **#7 吸收环（`已改`）**：`th12:0x44aa8e`（召唤）/ `0x44a42a`（每帧）写 `vm+0x430 = 敌人 + (32+192, 16)`，
  常量 `0x4a3d70`=32.0、`0x4a3d28`=192.0（场地半宽）、`0x4a3d68`=16.0（上内缩）**全是空间换算项**

  （`0x461e30` + 脚本 `pos(0,−28)`），本卡血条一直是 `(0,−28)` 且从没被报偏移。
