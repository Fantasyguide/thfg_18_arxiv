#### §th08-Q31 定案：归航「飞得慢」= `yk_fsqrt` 没收敛（2026-09-23）

- **错在算模长的那一步**：旧 `yk_fsqrt` = 「初值 = v，6 次 Newton」，从 `x0 = v` 每步约减半，6 步只到
  `v/64 = d²/64`，而返回值该是 `d` ⇒ 越远误差越大。float32 逐点实测：

  | 距离 d | 旧返回值 ÷ 真值 | 该颗每帧位移（满速 10）|
  | ---: | ---: | ---: |
  | 64 | 1.31× | 7.62 |
  | **128**（符卡爆点那圈半径）| **2.16×** | **4.62** |
  | 256 | 4.08× | 2.45 |
  | 512 | 8.04× | 1.24 |
  | 768 | 12.03× | 0.83 |

- 符卡爆点撒点在**半径 128**、自机还可能离 boss 更远 ⇒ 全落在这一段 ⇒ 观感「爆出来那一片飞得慢」。
- 修法 = 指数减半初值（IEEE754 bit trick，**纯整数 ⇒ 不进 x87**）+ 2 次 Newton ⇒ 全量程相对误差 0。
- **教训**：手感里「越远越慢」这类**距离相关**的问题，先去怀疑那一步的数值近似有没有收敛。
