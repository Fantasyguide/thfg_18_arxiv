## 2. ★ 跨卡 / 共享件改动（**统筹重点看这一节**）

### 2.1 动了**别人的卡**（112 / 117）—— 已按协作纪律登记

起因：owner 要 92「把场上所有可收集道具变成金钱」，其中点名「**112 飞碟 token 与 117 动物灵 token 都变成 10 个**」。
这两批 token **不在引擎道具池里**（各卡 `.c` 的私有池）⇒ 只能由**那张卡自己**清 ⇒ 必须动它们。

| 文件 | 加了什么 | 纪律 |
| --- | --- | --- |
| `native/cards/ufo.c`（**112**）| `ufo_sweep_to_money()` + tick 里一句 `ce_sweep_should_run` | 只**加**不改既有逻辑；文件内留注释；令牌消失走它自己的 `ufo_tok_vm_kill()` + `ufo_tok_remove()`（守住「令牌消失每条路都要过那里」的铁律，否则留幽灵 VM）|
| `native/cards/animal.c`（**117**）| `animal_sweep_to_money()` + 同款一句 | 同上；消失走它自己的 `token_remove()` |

> 两位作者**不需要来问**，但请看 [`AUDIT.md`](AUDIT.md) §BE 详录 **#219**（那里有逐文件表 + 为什么 + 怎么验证）。

### 2.2 新增的**共享层**（谁都可以用）

| 文件 | 新增 | 用途 |
| --- | --- | --- |
| `sdk.h` | `ce_money_pocket(int n)`（inline）| 一枚 type 2 金钱道具的**等价记账**（`MONEY`/`MONEY_TOTAL`/`MONEY_ITEMS` 三字段，一手 `ItemManager__collect_money_item` `0x446d2e`）⇒ **道具池满撒不出来时用它**，两个钱口径不会打架 |
| `sdk_core.h` / `sdk_core.c` | **清扫代数闸** `ce_sweep_bump/_gen/_should_run` | 与 88 的**复制闸**同形：92 发动时 `bump`，有私有池的卡在自己 tick 里 `should_run` ⇒ 清自己那批。**接一张新卡只需要一句 + 一个清扫函数** |
| `native/tests/test_dup_layer.c` | `test_sweep_gate` | 三条不变式：第一次只登记 / 每代正好一次 / `NULL` 安全 |

**想让别的卡也响应清扫**（把自家私有掉落物清成钱）：在它的 tick 里加
`static uint32_t seen; if (ce_sweep_should_run(&seen)) my_sweep_to_money();`，清扫函数里对每个实体
`ce_spawn_item(2u, pos, …)`，池满的走 `ce_money_pocket(1)`。
