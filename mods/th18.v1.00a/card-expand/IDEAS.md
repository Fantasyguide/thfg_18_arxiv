## 0. 现状一句话与三条铁律

SDK 面（2026-09-09，辉针城 127 整卡实跑之后）：24 张卡（id 58–80 + 127）+ 11 个事件
（item 三件套 / `on_shot_damage` / `on_enemy_drop_pre` / `on_bomb_spent` / `on_shop_open` /
`on_item_score`（**断点已挂、暂无用户**）/ `on_item_money`）+ 主动卡 / 装备卡 / 即时卡三套模板 +
子机 + SHT shooterset + HUD 文字 / 数字 / 图标 + VM 演出 + 语音。大多数「别的作的系统」= 这些件的组合。

1. **id 只取 81–126，从 126 降序拿**（Z11：编成 deck 槽把 > `0x7f` 当负值剔除，所以上限 127；
   127 已被辉针城占）。id 与图鉴 / 编成排序**无关**（[`DATA.md`](DATA.md) §2：menu 按 `category` 插入），
   换实现顺序 = 换号，零代价。
2. **新卡总数 ≤ 71**（[`DATA.md`](DATA.md) §4 硬上限，imm8）：已用 24 → 空位 46，本文全部点子装得下。
