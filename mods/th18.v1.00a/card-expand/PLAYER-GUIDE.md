# 卡牌手册（106–117）

装上这些卡以后，游戏里会多出什么、怎么用、代价是什么。每张卡一节。

- 卡号 **106–117 = 原作编号 + 100**：106 = **红魔乡**、107 = **妖妖梦**、…、117 = **鬼形兽**，
 一看编号就知道是哪一作。

## 速查

- **106 东方红魔乡** —— 被动卡，放进卡组就一直生效 —— 不满火力（未满 P）时飞过收点线不会把道具吸上来，火力满了才恢复「过线全吸」；同时整局不再画那条收点线指示，低速时自机的判定点指示也会消失。
- **107 东方妖妖梦** —— 装上后左下角出现三行读数：`+C` / `樱点` / `最大樱点`。击中敌人、收下道具都攒樱点，樱点越高，收金钱（点）道具的得分越高；`+C` 满 50000 会自动展开「森罗结界」9 秒。
- **108 东方永夜抄** —— 装上后机体多出一个「妖侧」形态：高速是原版人侧，按住 Shift 变妖侧（换机体外观、换弹幕、放出低速子机）。场上每个敌人发弹口还会长出一只可打的「使魔」——人侧看得见、打得掉，打掉后那个发弹口哑火；使魔挨到的伤害会全额转给它的母机。同时带上**永夜抄**的人妖槽、永点（刻符）与夜点。
- **109 东方花映塚（开发中）** —— 装上后多两条互不相干的线 —— 按住 `C` 蓄力，松手放出**逐帧扩张的红色消弹圈**（四档，后两档是「把自己当 boss、从版底往上打符卡」）；按住 `C` 或 `Shift` 张开**固灵结界**，把碰到的敌弹变成拾取用的**灵力道具**。灵力攒得越多，下一发蓄力攻击能蓄到的档越高。
- **110 东方风神录** —— 装上后，左下角出现**风神录**系列的信仰栏（一根蓝点 + 三行读数：信号强度槽 / 最大得点额外值 × 倍率 / 连击槽）。战斗里敌人会掉下绿色信仰点，吃到就涨「信仰」，信仰越高，**金钱道具的得分越高**。同时这张卡让你多出一种灵击——按下去在自机周围撑开一圈消弹 + 打伤害的冲击。
- **111 东方地灵殿** —— 装上后左下角多一条「信号」槽（0.00–130.00）。在回收线上方待着槽就涨；满 100.00 时**全屏道具自动飞向自机**；掉到线下槽就慢慢退。槽越满，金钱道具（蓝点）的**得分**越高——**不加钱的数量**。擦弹还有一份倍率加成。机体不同还会额外拿到三条「支援特技」。
- **112 东方星莲船** —— 装上后，击破被换上飞碟皮的妖精 / 大蝴蝶与 Boss 会掉出「飞碟碎片」；收满 3 枚就召唤一只飞碟敌机。飞碟在场时会把**全场的 P 点与金钱点**往自己身上吸，吸满或把它打掉都会吐奖励。
- **113 东方神灵庙** —— 装上后，击破敌人会掉出「神灵」；左下角的灵界槽（3 格）就会被一点点填起来。槽满后按 C 进入「灵界」：一段时间内主炮换成灵界专属弹、自机变白剪影、画面与 BGM 一起换成**灵界版**，而且不会中弹。中弹时还会自动开一次灵界把这次死亡顶掉——但那只是延时，灵界走完仍然要死一次。
- **114 东方辉针城** —— 装上后，**辉针城**的「收点批」 —— 你把 P 点与钱收成一批，批够大时按档位结算分数、每批再掉 1 枚碎片卡（命碎 / 符卡碎）。另有一座被动：只要用高速射击打中敌人，敌人身上会间歇掉出 P 道具。
- **115 东方绀珠传** —— 被动卡，卡组里带上就生效。自机周围多出一个「擦弹圈」——进圈的敌弹变橙黄、自机身上浮出一圈暗环，同时场上正在飘落的掉落物变慢；另外道中与 boss 战按「一波」切章，每波结束时按「擦弹数 × 击破率」结一次章节奖，涨分数与最大得点，够高还掉一枚残机碎片，并在画面中左弹出一块结果面板。
- **116 东方天空璋** —— 装上后，**擦弹 / 击破敌人 / 发动解放消弹**都会掉出「季节点」；捡起季节点累积**季节等级（0～6 档）**，等级越高，跟在你身后的**季节子机**越多（最多 6 颗），火力与得分也越高。攒够等级后可以发动**季节解放**：清掉范围内的敌弹、对敌人持续造成伤害，并给自己一段无敌。
- **117 东方鬼形兽** —— 装上后，被击破的敌人会掉出「动物灵」，靠近自机收进左下角 5 格槽；收满 5 格**不用按键**就自动进入咆哮——主炮整组换成兽灵专属弹幕（狼 / 鹫）或召出 3 颗环绕光球（水獭），同时自机身上亮起光环、上方出现就绪条。咆哮可以按 X 主动用成一次霊撃（消弹 + 无敌），也可以在中弹时替玩家挡掉一次死亡。

### 106 东方红魔乡

**作用**：被动卡。放进卡组就一直生效，不需要发动。

两条可见效果：
- **不满火力（未满 P）时，飞过收点线不会把道具吸上来**，得自己撞上去吃；火力打满后恢复「过线全吸」。
- **整局不再画收点线**指示（满 P 时也不画）；**低速时自机的判定点指示也会消失**。

**怎么用**：
得分照旧（在线上收的仍是满额）。
- **挨弹的判定范围一点没变**，只是看不见那个点。

**代价**：
- 不满 P 时收点线不吸道具——想靠过线白拿全屏道具，就必须先把火力打满。

> 卡上还额外记着一个**红魔乡**的 **Rank** 值（收点、擦弹、吃道具会涨，中弹与放 B 会掉），
> 但它目前**不影响弹幕、出怪、得分或难度**，界面上也看不到。

**与其他卡一起装**：
- **111 地灵殿（信号槽）**：不满 P 时会把 111的「在线上就把信号强度补满」关掉；擦弹涨信号、线下衰减照旧。
- **110 风神录 / 111 地灵殿的信仰点**：不满 P 时这些信仰点也不会被真空吸走，要碰到才收（刻意如此）。
- **24 献给神山的供物（八坂神奈子）**（把回收线下移的那张原生卡）：本来要装上它才会出现那条指示线；有 106 就整局不画，106 不满 P 时也会压过它降的线。
- **109 花映塚（开发中）**：同装时 Z 变成花映塚的 Z。

**已知现象**：
- **收点线整局不画**（照**红魔乡**原作来，原作本来就没有）。

### 107 东方妖妖梦

**作用**：装上后左下角出现三行读数：`+C` / `樱点` / `最大樱点`。击中敌人、收下道具都攒樱点，樱点越高，收金钱（点）道具的得分越高；`+C` 满 50000 会自动展开「森罗结界」9 秒。

**怎么用**：
- 开结界瞬间：粉色六芒星环绕自机并随时间缩小，背景变暗，自机红白闪，画面上方滑入一行 `Supernatural Border!!`。
- 结界 9 秒里：自动把场上所有道具吸走（含 **110 风神录** / **111 地灵殿**的信仰点），`+C` 那一行变成倒计时往下掉。
- 按 `X` 放炸弹：炸弹照常放，同时结界以「灵击」提前崩掉 —— 全屏弹变成灰点飞向自机，每颗收下樱点与 `+C` 各 +20，并给约 0.67 秒（40 帧）无敌。
- 中弹：结界替你挡掉这次死亡（同样以灵击崩结界 + 那 0.67 秒无敌）。
- 撑满自然到期最划算：樱点与最大樱点各 +10000，并从右侧飘出 `Border Bonus <数字>`。
- 樱点顶到「最大樱点」时那一行变金黄并提示 `CherryPoint Max!`，此后继续攒樱点是浪费 —— 只有结界中擦弹或结界自然结束能把最大樱点抬高。

**代价与冷却**：
- 无冷却、无消耗品；`+C` 就是结界槽，开一次结界即清零重攒。
- Miss：樱点扣掉当前值的一半（单次最多 10 万）；放炸弹：樱点扣掉四分之一。两者都不动 `+C` 与最大樱点。
- 结界被打断（中弹或按 `X`）拿不到自然结束的 +10000与 Border Bonus。
- `+C` 满时若正在放炸弹，结界会排队等炸弹结束再开。

**关键数值**：

| 项目 | 数值 | 什么时候发生 |
| --- | --- | --- |
| 开结界门槛 | `+C` 行满 50000 | `+C` 只涨不跌，集满即开 |
| 结界时长 | 9 秒（540 帧） | 开结界后，`+C` 行随剩余时间线性掉回 0 |
| 命中敌人加值 | 每次 +10～70 樱点（关卡越靠后、单次伤害越高越多，上限 70） | 自机弹命中敌人（含小怪）时 |
| 收点加值 | 灰点（消弹点）樱点与 `+C` 各 +20；大樱点 `1000 + 100 × 本关收掉的符卡奖励次数`（樱点与 `+C` 各一份）；小樱点每颗 +100 樱点、其中 +30 进 `+C` | 收下对应的点道具时 |
| 结界中擦弹 | 樱点与最大樱点各 +80（高速）／各 +30（聚焦低速） | 结界展开中擦弹时 |
| 樱点 → 得分 | 金钱（点）道具得分 = 50000 起，樱点每超过 50000的部分 ÷5，向下取整到 10 | 收金钱道具时 |

**与其他卡一起装**：
- **110 风神录 / 111 地灵殿**：三张卡的点会一起结算。满火力时一颗 P 道具被吃掉，会**同一帧**撒出 110的信仰点、111的中信仰点、107的大樱点（外观与飞散角度不同，不会叠在一起）；结界里的全屏收点也会把它们的信仰点一并收走。只装 107 时妖精不会变绿。
- **112 星莲船**：满火力时樱点对飞碟算「P 点」，彩色飞碟会吸、红飞碟会加倍；不满火力时樱点不参与。彩色飞碟满 P 吸金钱时会额外吐 1 颗樱点 + 1 颗中信仰点。飞碟会把场上的樱点道具一起吸走，开奖时按原值 1:1 归还；压缩包被吃下时，包里吸到的樱点会返还到樱点（**88 杰拉**复制出的第二个包也照此加倍）。
- **113 神灵庙 / 117 鬼形兽**：中弹时救援顺序是 **107 妖妖梦** → **117 鬼形兽** → 决死 B → **113 神灵庙**。107与 117 同时就绪时两张都烧掉（结界与咆哮都用掉），全屏消弹只算一次（记在 **107 妖妖梦** 头上），无敌取两者最大值。
- **92 伟大之作**：发动清扫时，场上的樱点道具（连 **110 风神录** / **111 地灵殿**的信仰点）会被换成金钱道具，每颗 1 枚。
- **114 辉针城**：两张卡的奖励飘字会同时显示，不互相顶掉。

**目前已知的问题**：
- 中弹触发的那次全屏消弹会晚一帧（约 16 毫秒）才发生。
- 装卡后，装卡前录下的 replay 会失步。
- 与 **110 风神录** / **111 地灵殿** / **112 星莲船** 同装时，火力打满那一刻会删掉原生 P与大 P 道具，112 需要的「满 P 之后继续掉的额外 P 点」会收不到。
> **别被"删掉"吓到** ：装 **107 妖妖梦** / **110 风神录** / **111 地灵殿** 时，它们自带的**樱点与信仰点额外规则**会把这份 P 点数补回来 —— 从**总数**看并没有变少，同装时甚至更多 。
- 消掉 n 颗弹不等于拿到 n 颗灰点（画面边缘与上下的弹不产点）。
- **全屏消弹会掉两种点**：**星星样的**是 TH18 自己的消弹点（收一颗 +20 樱点与 `+C`）；**樱花样的（小樱点）**只在**符卡刚结束**那一刻、本帧有一大笔没被其他系统消耗掉的消弹时撒出来 —— 樱点 +100、`+C` +30（位置是以自机为中心的一圈）。

### 108 东方永夜抄

**作用**：装上后机体多出一个「妖侧」形态 —— 高速是原版人侧，按住 Shift 变妖侧（换机体外观、换弹幕、放出低速子机）。场上每个敌人的发弹口还会长出一只可打的「使魔」：人侧看得见、打得掉，打掉后那个发弹口哑火；使魔挨到的伤害会全额转给它的母机。同时带上**永夜抄**的人妖槽、永点（刻符）与夜点。

**怎么用**：

- 被动卡：装上即生效，不占 C / D / X 键，只用 Shift 换形态。
- 松开 Shift = 人侧（高速）：原版机体与原生弹幕，和没装本卡一样。
- 按住 Shift = 妖侧（低速）：外观换成**永夜抄**的妖侧外观，弹幕换成妖侧出弹组（本体与子机都发），并放出低速子机。
- 低速子机台数：灵梦 1 / 魔理沙 1 / 咲夜 4 / 早苗最低火力档 0 台、升一档后 1 台。

**人妖槽（人 / 妖两侧）**：原作把两个形态叫「人」与「妖」，这条槽就是**人妖槽**。按住射击键持续开火，会把它往当前形态那一侧推。前 15 帧不动，之后阶梯加速，约 5 秒到顶（+0.20%/帧）。放符卡 / 炸弹期间改成固定 ±0.26%/帧。松开手指约 30 帧后开始回中：槽离中线越远回得越快，每帧 ±0.05%（极人 / 极妖）、±0.03%（中人 / 中妖）、±0.02%（贴近中线）；|槽| ≤ 0.09% 时直接归零。妖侧擦弹每颗 +1.00%；中弹死亡那一帧清零。

**永点（刻符）**：击破敌机、敌人死亡时在原地张开的消弹圈、妖侧擦弹、逢魔击破都会出。收到后左下角槽条下方那排数字（夜点）会涨：开局显示 000000，每 2 颗 +10。夜点同时是你蓝点道具的分值。

**使魔**：人侧可见、可打掉、撞到会 MISS；妖侧不可见（只画一圈魔法阵）、打不掉、可以穿过去。打掉一只使魔后，它对应的发弹口哑火，到下一批敌人出现时、或最长约 10 秒后自动重建。

**形态锁定**：放炸弹（B）持续期间形态锁住；113 灵界 / 117 暴走咆哮进行中也锁住。这时按 Shift 照常聚焦，只是形态不换；灵击不算「放 B」，仍可切。

**代价与冷却**：无消耗、无主动冷却。风险：① 人侧撞到使魔（**它们都是敌人**）= 一次普通 MISS（和其他 MISS 一样，救援与防护照常生效）；② 人侧打掉使魔要付代价（**永夜抄原版就是这样**） —— 槽按当前值扣 1/12（约 8.3%）、掉 1 颗永点、之后 50 帧内收永点不再给槽。

**关键数值**（游戏里看得见的口径）：

| 项目 | 数值 | 什么时候发生 |
| --- | --- | --- |
| 人妖槽量程 | 显示 −100.00% ~ +100.00%；反方向最多只推到 ∓20.00% | HUD 槽条，每帧 |
| 逢魔（极人 / 极妖）| 阈值 **±80.00%**；进逢魔后每帧给显示分 | 每帧判定 |
| 击破敌机 | 妖侧（聚焦）+2.00% / 人侧（非聚焦）−2.00% | 击破时 |
| 收一颗永点 | +1.11%（聚焦）/ −1.11% | 收永点时 |
| 逢魔 | 每帧 +100 显示分（对话中不加）；每次击破额外掉 1 颗永点 | 逢魔期间 |
| 发射口使魔血量 | 母机血量 ÷3（母机 ≤200 血时恒 100） | 每次建使魔 |

**与其他卡一起装**：

- **106 红魔乡**：卡组里有 106 时，决死 B 消耗 2 个炸弹（不会扣成负数，最后一个 B 也能决死）；没有 106 则完全不生效。
- **111 地灵殿**：两张都管低速子机，同时装时场上只有 108的子机（111 让位，不另外放出自己的子机）。
- **71 破损核心 / 77 豌豆射手 / 116 天空璋**：四张卡共用全卡组那 12 个低速子机位；108 满配占 4 格、留 8 格给它们。抢不到格子就每 60 帧重试（关卡中途才买 108的话，子机可能晚一会儿才出）。
- **113 灵界 / 117 暴走咆哮**：进行中按 Shift 不换形态（子机不放不收、妖侧弹幕不换），聚焦照常。
- **109 花映塚（开发中）** / **112 星莲船** / **116 天空璋** / **117 鬼形兽**：全屏消弹同一帧发生时，如果别人这一帧已经消掉了弹，那一刻 108 就跳过这批弹、不再重复出永点 —— 同一批弹不会被两边各算一次，也不会重复变成永点。
- **88 杰拉**：它复制场上掉落物时，108的永点也会按原位各被复制一颗。
- **115 绀珠传**：115 也给弹幕上色，和 108 决死窗口染红用的是同一种颜色；同一颗弹同帧被两边染色时，只显示其中一种。

**目前已知的问题**：

- 商店卡面文字写「伤害减半」，当前实际是全额转嫁 —— 以实际为准。
- 早苗在妖侧只有 1 台子机、且全堆在画面正中间 —— **她的妖侧外观与弹幕沿用「东方天空璋」的文文**。
- 低速子机要抢**全卡组共用**的 12 个低速子机位，抢不到要等 60 帧重试。
- 擦弹出的永点直接从自机身上冒出来（原作出现在被擦到的那颗弹上），看不到它从弹上飞过来。
- 发射口哑火后约 10 秒自动重建。

### 109 东方花映塚（开发中）

（开发中：这张卡现在能正常使用，只是效果与数值还可能调整。）

**作用**：装上后多两条互不相干的线 —— 按住 `C` 蓄力，松手放出**逐帧扩张的红色消弹圈**（四档，后两档是「把自己当 boss、从版底往上打符卡」）；按住 `C` 或 `Shift` 张开**固灵结界**，把碰到的敌弹变成拾取用的**灵力道具**。灵力攒得越多，下一发蓄力攻击能蓄到的档越高。

**怎么用**：
- **蓄力**（只认 `C`）：按住 `C` 开始涨蓄力值，**松开的那一帧**发一发；蓄力值**松手即归零**，按住再久也只出一发。

- **攒灵力**：打掉敌人 / 结界碰掉敌弹 / 打掉灵，都会掉**灵力道具**；捡到就涨「灵力」（开局 500，上限 2500）。
- **节奏**：档位由**松手那一刻的蓄力值**决定，而蓄力值又被**当前灵力**封顶 —— 灵力不够就蓄不到高档，这是这张卡的骨架。

**代价与冷却**：
- 蓄力**占着** `C` 与 `Z`：按住 `C` 的整段时间里 `Z` 位被清掉（主炮与所有子机这一帧都不发弹），松开立刻恢复。

- 拿到卡时**送一个抵挡护罩**。

### 112 东方星莲船

- 击破的奖励：一次大范围消弹＋ 一个**压缩包**（自动飞向自机，吸过至少一颗点才掉）＋ 颜色加成（红 = 残机碎片卡 · 绿 = 符卡碎片卡 · 蓝 / 彩虹 = 无）＋ 返还 1 枚变色碎片。

**代价与冷却**：

- 这张卡的代价是「飞碟把你的 P 点与金钱点从场上吸走」，**全场不分距离**，清不掉也拦不住。

### 114 东方辉针城

**作用**：装上后跑起**辉针城**（TH14）的「收点批」系统 —— 你把 P 点与钱收成一批，批够大就按档位结算分数，每批再掉 1 枚碎片卡（命碎 / 符卡碎）。另有被动一条：用高速（不聚焦）射击打中敌人，敌人身上会间歇掉出 P 道具。

**怎么用**：被动卡。装上就生效，不用按键，不占 C。

- **只有「自动飞向自机」的 P / 钱才算数。** 过收点线（PoC）之后、放 B 时、对话中，P / 钱会朝自机飞过来（下文称「自动飞向自机」）—— 这样收到的才计数、才开批。平时撞到的、或 70 px 环吸过来的 P / 钱，**不算**。
- **批会等。** 场上还有正在自动飞向自机的 P / 钱，就一直吊着不结算；真的没有在飞的了，再等 8 游玩帧（约 0.13 s）才结算。
- **结算画面。** 批 ≥20 时，在「批位」（最后一枚成员加入时的自机位置） 弹出「BONUS ×倍率」和这批的分值，并响一声收点钟声。
- **碎片。** 结算后 20 帧（约 0.33 s），从**收点那一刻的位置**上方弹出 1 枚碎片卡。
- **满 P 时。** 收到「满 P 道具」→ 额外最大得点 +100（界面上显示的数字）。
- **掉 P。** 不按低速、不在放 B，射击命中敌人 ⇒ 在敌人中心掉一颗 P。火力越高，掉得越密。

**代价与冷却**：唯一的金钱开销是商店 300 金钱。代价出在批上：

- 批 20–29是 **×0.5**、30–39是 **×0.8** —— 这是**倒扣**：这批 P / 钱原本给的分数会被扣掉一半 / 两成。

- 掉 P 有间隔下限：最短 1 帧，满火力时约 32 帧（≈0.53 s）一颗。
- 人走开了就得回去捡，掉出画面就没了。

**关键数值**（游戏里能看到的数字）：

| 项目 | 数值 | 什么时候发生 |
| --- | --- | --- |
| 批档位 → 分数倍率 | 20–29 ×0.5 / 30–39 ×0.8 / 40–49 ×1.2 / 50–59 ×1.6 / ≥60 ×2.0（倍率只作用这批道具原本给的分数） | 批结算那一刻 |
| 批不到 20 | 不给碎片；5–19 弹一次灰色「NO BONUS」，<5 什么都不弹 | 批结算那一刻 |
| 这一批什么时候结算 | 场上没有还在自动飞向自机的 P / 钱，再等 8 游玩帧 | 收点停下来之后 |
| 每批碎片 | 1 枚；符卡碎连出 4 枚后，第 5 枚换成命碎；批 ≥60 直接命碎 | 批结算后 20 帧弹出 |
| 满 P 道具 | 额外最大得点 +100（界面上显示的数字） | 火力满时收到「满 P 道具」 |
| 非聚焦命中掉 P | 间隔 = 96 − 火力×16 帧（火力 0.00 → 96 帧；4.00 → 32 帧），最小 1 帧 | 非低速、非放 B的射击命中敌人时 |

**与其他卡一起装**：

- **110 风神录 / 111 地灵殿**：大 / 中信仰点被自动飞向自机收进来时也计入批（+1 颗），在飞期间同样会把批吊住。但信仰点**不进批分** ⇒ 只由信仰点凑成的批不给额外分数（档位提示与碎片照出）。消弹掉出来的那种小颗信仰点不算。
- **112 星莲船 / 113 神灵庙 / 115 绀珠传**：和 114 共用同一份「额外最大得点」数 —— 同装相当于几套系统都往同一份数里加（值更高），但进分数只算一份，不会把同一笔数两遍；每张卡各自有加分上限。另外「每擦弹 +1 最大得点」这一项四张卡同族，**只算一次**。112的飞碟把道具吸走时，那些道具不算进批（不会双计）。
- **107 妖妖梦 / 111 地灵殿**：两家的全屏收取（107的森罗结界、111的满槽全收）会让场上道具也朝自机飞过来 ⇒ 那些 P / 钱也会进 114的批。107与 114的奖励弹字各占各的显示位，同屏不会互相顶掉；107与 114的命中计数各算各的，互不影响。
- **70 腐化**：70 把炸弹上限顶满并清碎片 ⇒ 114 给的**符卡碎片会直接消失、拿不到**（命碎不受影响）。
- **60 黑桃 Q**：60 把道具吸引半径从 70 改到 95 ⇒ 更多道具只是被吸住、还没开始自动飞向自机 ⇒ **批会变小**。
- **88 杰拉**：复制场上的碎片卡道具时，每一枚复制品被收下都会真的变成一张碎片卡 ⇒ 与 **114 辉针城** / **117 鬼形兽**的碎片叠加时一次能拿好几枚。

**已知问题**：

- 碎片是从「收点那一刻的位置」弹出的，捡取时要留意。
- 结算弹字在暂停时不会被模糊罩住，这是原作就有的现象，不是故障。
- 某颗道具的分数若在结算之后才算进来，它**不计入本批**（这批分因此略少一点）。

### 115 东方绀珠传

**作用**：被动卡，卡组里带上就生效。自机周围多出一个「擦弹圈」——进圈的敌弹变橙黄，自机身上浮出一圈暗环，同时场上正在飘落的掉落物变慢。道中与 boss 战还会按「一波」切章：每波结束时结算一次章节奖，按「擦弹数 × 击破率」计算，涨分数与最大得点，够高还掉一枚残机碎片，并在画面中左弹出一块结果面板。

**怎么用**：

- **不需要按键**：，这张卡只需要带在卡组里。
- 想让减速和擦弹圈生效，只要**把弹幕放进擦弹圈**：判定框外扩 24 px；（有效擦弹半径约 43–50 px）。
- 减速是**「圈里有弹就一直慢」**，而不是只慢擦到的那一下。弹出圈后约 0.12 s 恢复满速 ⇒ 贴着弹幕走可以长时间维持慢速。
- **章节边界（道中）**：按关卡里敌人出现的波次切章，同一组的后续小段不另开章。道中 boss 进场会额外插入一个短章（约 260 帧 ≈ 4.3 s）。
- **章节边界（boss 战）**：一段攻击 = 一波，即一个非符一波、一张符卡一波，boss 进场也算一波。
- **击破率**：道中 = 本波击破数 ÷ 本波刷出数（一只都没刷出时按 100%）；boss 非符 / 符卡 = 打空 100%、超时 0%；时符（耐久符卡）恒 100%，所以时符拖满时间也能拿满分。
- **结果面板**：每次结算弹出，保留约 300 帧（≈5 s）后自己淡出。

**代价与冷却**：无消耗、无冷却。注意：

- 减速对**全场**生效，不只自机脚下；还在上抛、以及已经被吸向自机的道具不受影响（只有「正在飘落」那一段变慢）⇒ 它拖慢的是还没捡到手的那批。
- 结果面板会**压住游戏原本显示符卡名的那一行**（面板在场的约 5 s 内）。
- 自机靠近面板（进入面板外扩 28 px的范围）时整块淡到 25% 不透明。靠近变淡是这张卡加的，原版没有。

### 116 东方天空璋

**作用**：装上后，**擦弹 / 击破敌人 / 发动解放消弹**都会掉出「季节点」。捡起季节点累积**季节等级（0～6 档）**；等级越高，跟在你身后的**季节子机**越多（最多 6 颗），火力与得分也越高。攒够等级就能发动**季节解放**：清掉范围内的敌弹、对敌人持续造成伤害，并给自己一段无敌。

**怎么用**：
- **平时**：擦弹、抢在敌人出场后尽快击破、以及用解放清弹，都会出季节点。点会先飞散再飘落，然后被自机吸走。每颗点 +10 分，并给 1 个季节点。

- **发动解放**：像其他主动卡一样，**按 D 键切换到本卡**，再**按 C**。等级 0、或正在解放中会被拒绝。
- **切副季节**：**完整双击 Z**（不按 Z → 按 Z → 放开 → 再按）；两次按下之间要在 8 帧（约 0.13 秒）内完成才算数。顺序是春 → 夏 → 秋 → 冬 → 土用 → 春。切换时子机整批重做，会有一次出场动画。
- **节奏**：副季节决定子机的弹种与射速，等级只决定子机的**数量**。想换输出方式就切副季节，想加火力就攒等级。
- **跨关保留**：季节点、等级与副季节在换关的商店里不清空；只在**新的一局**或**删掉这张卡**时归零。

**代价与冷却**：
- **解放的消耗**：春 / 秋 / 冬 解放后**整个季节槽清零**（等级归 0，子机一颗都不留）；夏 / 土用 只**退一档**。
- **冷却**：没有额外的时间冷却；解放期间不能再发动，放完即可再按 C（只要还有档）。
- **风险**：等级 0 不能发动；一按下去就扣槽，清屏与伤害都按**按下当时的档位**结算，等级低时放收益小。

**定位**：装备（子机）件，按住 Z 才开火的穿透炮。
**数值**：每 12 帧朝最近的敌人射出一颗穿透星星，每次命中 12 伤害；一个弹匣 300 发，打满后变灰装填 180 帧（3 秒）；消弹 / 命中时把每敌每帧上限抬到 200。
**怎么用**：① 按住 Z 且场上有敌人它才开火，清杂时一路穿透；② 300 发打满会强制装填 3 秒，boss 战前留一匣。
**注意**：卡面「三百颗够吗」问的就是这个弹匣；不显示弹药数字，弹匣空了只能看它变灰；锁敌最近 640 px，没有目标时朝正上打。

### 90 冰淇淋

**定位**：被动件，miss 的惩罚减半。
**数值**：Miss 时不会损失火力，且符卡直接 +3（正常 miss 是掉一档火力、符卡重设为 3）。
**怎么用**：① 火力高、又容易撞的局带它，死后火力原样保留；② 与 **78 衔尾蛇**同装，miss 叠层不掉火力，越死越强。
**注意**：符卡是「生前的数量 +3」再按上限封顶，不是固定 6 张；只有真死才生效，被决死 B 救回来不算。

### 91 鞘翅重锤

**定位**：主动卡的高额单体爆发 + 无敌。
**数值**：按 C 进入无敌并弹出时机条，有敌人时光标左右扫，在中间亮带里再按一次 C ⇒ 瞬移到最近敌人上空、重锤砸下 800 伤害后回原位；瞄准总预算 3 秒（180 帧），砸下 / 位移各 18 / 12 帧，退出留一段无敌缓冲。
**怎么用**：① 用来打断高威胁符卡 / 收残血 boss，800 一下很实；② 亮带在正中间，提前半拍按，别等光标到边。
**注意**：3 秒内没有敌人 / 没卡准 / 按 D 切走都会自动退出，退出时同样给一段缓冲无敌；进入瞄准后第二次按 C 是确认键，不会二次发动、也不会重复扣充能。

### 92 伟大之作

**定位**：主动卡的「清场 + 换钱」，代价是自机也死一次。
**数值**：按 C 把场上所有弹幕与敌人变成金钱道具；敌人按剩余血量换钱（每 20 血 1 枚、单敌上限 40），boss 期间改成直接击破一个阶段；冷却 = 360 + 弹幕数 × 2 + 场上敌人血量总和，钳在 360～5400 帧；空场不消耗。
**怎么用**：① 满屏弹幕时按，清屏 + 换一大袋钱；② 自机在发动后第 60 帧「化为黄金」= 真的死一次，**那一帧身上还有无敌就不会死**——可以先开 **91 鞘翅重锤** / **116 天空璋** 这类给无敌的卡再按。
**注意**：卡面「发动后自机也会一起化为黄金」不是演出，是真的扣一条命；没有无敌时等于用一条命换一屏钱 + 一个 boss 阶段，值不值自己算。
