## 3. 目标机制（合成卡；细节见 SPEC）

```
按住 C（电平 CE_INPUT_HELD() & 0x400）
   ├─ 固灵结界常驻（形状取一套几何；视觉走卡侧 VM）
   └─ 蓄力推进 → 4 档（可放档 = min(档, 槽)）
场上：消弹 / 击破 / 结界碰敌弹  →  掉「灵力道具」  →  拾取  →  攻击槽 +点
灵：按周期循环生成（同屏 ≤ 4；boss 在场不撒）= 自制 TH12 UFO 型真敌人
结界对灵：沈静化（停住 + 耐久骤降 → 成佛）
松开 C → 放档（消弹圈 + 无敌 + 伤害，沿用现有 ca_effect）
❌ 不做：敌弹/敌人减速（口径 3）、送り込み、胜负轴
```
